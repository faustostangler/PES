# Ubiquitous Language Glossary — PES Strategic Knowledge Monolith

This glossary establishes the canonical terminology across all engineering discussions, code identifiers, comments, documentation, and tests for the PES workspace.

---

## 1. Domain Entities & Value Objects

| Canonical Term | Pronunciation / Context | Definition | Aliases to AVOID |
|---|---|---|---|
| **`ContentId`** | Value Object | Strongly-typed unique identifier for a raw media item or transcript, derived from video ID or content hash. Enforces non-empty string and regex validation. | `id`, `video_id_str`, `raw_id`, `cid` |
| **`NoteTitle`** | Value Object | Validated canonical title of an Atomic Note, automatically sanitized of `[[` brackets, path characters, and trailing whitespace. | `title_str`, `name`, `clean_title`, `nt` |
| **`NoteType`** | Value Object | Enumerated typology classification restricted to: `concept`, `entity`, `event`, or `process`. | `tag_type`, `category`, `kind` |
| **`CausalMatrix`** | Value Object | Immutable ternary attribution model defining `cause` (underlying premise), `effect` (observable outcome), and `epistemic_attribution` (origin author/school). | `matrix`, `causality`, `premise_pair` |
| **`CrossContextRelations`** | Value Object | Immutable triad connecting a concept to its historical `precursors`, synchronous `lateral_events`, and systemic `aftermath`. | `context_net`, `network_links`, `relations`, `pre/lat/aft` |
| **`StageTranscript`** | Entity / Aggregate (Base) | Immutable monomorphic domain envelope composing the 3-VO Triad (`Channel`, `MediaProvenance`, `Content`) across pipeline transformation stages per ADR-038, ADR-054, and ADR-057. Enforces structural parity and pure Value Object construction, delegating Markdown formatting rules to `LlmJudgePort`. | `BaseTranscript`, `TranscriptEnvelope`, `TranscriptDTO` |
| **`SourceTranscript`** | Entity / Aggregate | Canonical input aggregate representing verbatim spoken audio or canonical source prose alongside creator provenance (`ChannelName`), inheriting from `StageTranscript` per ADR-010, ADR-031, ADR-038, ADR-054, and ADR-057. | `raw_text`, `transcript_dump`, `RawTranscript`, `audio_text`, `raw` |
| **`FluidTranscript`** | Entity / Aggregate | Detranscribed clean fluid narrative prose without speech noise, oralities, or tables, inheriting from `StageTranscript` per ADR-028, ADR-038, ADR-054, and ADR-057, persisted atomically in `data/fluid/` with YAML frontmatter per ADR-043. | `cleaned_transcript`, `fluid_text`, `raw_article`, `fluid` |
| **`CandidateText`** | Value Object | Strongly-typed, validated container for intermediate LLM transformation outputs across pipeline stages, enforcing non-emptiness per ADR-031. | `generated_str`, `completion_text`, `output_draft`, `curr_text`, `cand_text` |
| **`PipelineSessionId`** | Value Object | Holistic multi-stage content lifecycle session identifier formatted as `{channel_id}:{content_id}` (falling back to `{channel_name}:{content_id}` if no channel ID exists) ensuring end-to-end Session Replay in Langfuse for exactly one content item per ADR-016, ADR-027, ADR-033, and ADR-035. | `session_str`, `run_id`, `trace_session`, `sid` |
| **`Channel`** | Value Object (Composite) | Immutable composite entity/value object encapsulating `ChannelId`, `ChannelName`, and derived `tenant_key` (`channel:{tenant_slug}`). Pure 3-VO Triad component per ADR-032, ADR-033, and ADR-038. | `channel_str`, `ChannelTenantId`, `creator`, `ch` |
| **`Content`** | Entity / Aggregate | Pure domain aggregate representing the ingested media item with `ContentId`, `ContentTitle`, and `MediaProvenance`. Fully replaces legacy `Video` alias per ADR-032 and ADR-038. | `Video (banned alias)`, `item`, `media_record`, `cnt` |
| **`MediaProvenance`** | Value Object | Immutable domain container encapsulating `SourceModality`, optional `MediaUrl`, optional `PublicationDate`, and extraction origin metadata per ADR-038. | `provenance_dict`, `source_meta`, `upload_meta`, `prov` |
| **`ChannelTenantId`** | Value Object *(Decommissioned)* | Legacy cost center identifier formatted as `channel:{channel_name_or_id}`. Decommissioned per ADR-033 in favor of the intrinsic `Channel.tenant_key` property on the `Channel` composite Value Object. | `tenant_id`, `cost_center`, `org_id` |
| **`UserIdentity`** | Value Object | Polymorphic identity representing the operator executing the pipeline (`anonymous`, identified via OAuth/IAM, or background system worker) per ADR-027. | `user_str`, `actor_id`, `principal`, `u` |
| **`TypedVerdict`** | Value Object | Strongly-typed evaluation judgment primitive returned by `LlmJudgePort`, categorizing results into `NOUL` (boolean), `CHOICE` (categorical), or `SCORE` (normalized scalar) alongside reasoning and improvement suggestions per ADR-031. | `judge_output`, `verdict_row`, `eval_result` |
| **`VerdictType`** | Value Object / Enumeration | Enumeration of evaluation output typologies (`NOUL = "noul"`, `CHOICE = "choice"`, `SCORE = "score"`) standardizing multi-provider evaluator responses per ADR-031. | `score_kind`, `eval_type`, `judge_kind` |
| **`JudgeCriterion`** | Value Object / Enumeration | Canonical evaluation criteria (`ORALITY_REMOVAL`, `SEMANTIC_FAITHFULNESS`, `NER_PRESERVATION`, `STRUCTURAL_COMPLIANCE`, `EPISTEMIC_CRITIQUE`, `AUTHORIAL_VOICE`, `EPISTEMIC_GROUNDING_SEGREGATION`, `CONCEPTUAL_MECHANICAL_DECOMPOSITION`, `BRAUDELIAN_STRATIFICATION`, `GENEALOGY_HIDDEN_AGENCY`, `COMPETING_HYPOTHESES`, `EXTRA_INFO_GRANULARITY`, `LINEAR_STYLE_NATURALISM`) evaluated by quality judges per ADR-029, ADR-031, ADR-039, and ADR-060. | `rubric_dimension`, `quality_metric`, `eval_criterion` |
| **`CriterionScore`** | Value Object | Quantified evaluation result for a single `JudgeCriterion`, encapsulating score, passed flag, reasoning, and optional improvement suggestion per ADR-029. | `metric_score`, `rubric_item`, `criterion_result`, `cs` |
| **`JudgeEvaluation`** | Value Object | Consolidated evaluation report across required criteria for a pipeline stage, aggregating `overall_score`, passed flag, friction metrics, and individual `CriterionScore` instances per ADR-029 and ADR-030. | `eval_report`, `judge_verdict`, `quality_review` |
| **`StageDefinition`** | Value Object / Domain Descriptor | Declarative domain specification in `StageRegistry` defining invariant stage metadata (`transform_prompt_key`, `required_criteria`, `judge_prompt_key`, `post_processor`) per ADR-031. | `stage_meta`, `stage_config`, `step_spec` |
| **`EnrichedCompendium`** | Entity / Aggregate | Continuous, dense, multi-pass factual prose document generated from a Source Transcript without bullet lists or tables, containing a mandatory 'Extra Info' section. | `article`, `expanded_text`, `summary`, `draft` |
| **`AtomicNote`** | Entity / Aggregate | A self-contained, highly-focused semantic unit in the Second Brain vault representing a single concept, entity, event, or process with standardized frontmatter, definition, WikiLinks, causal matrix, and cross-context links. | `note`, `card`, `wiki_page`, `markdown_file` |
| **`MapOfContent` (MOC)** | Entity / Aggregate | Navigational and conceptual synthesis document that groups and reconciles a thematic cluster of Atomic Notes with bidirectional links, ensuring zero orphaned notes. | `hub`, `index_page`, `toc`, `table_of_contents` |
| **`AtomicEntityInventory`** | Value Object | Deduplicated discovery manifest of distinct entities, concepts, events, and processes discovered across an Enriched Compendium prior to batch note generation. | `candidate_list`, `topics`, `tag_candidates` |
| **`DiscoveredMediaItem`** | Value Object | Immutable metadata descriptor (`content_id`, `title`, `published_at`, `media_url`) representing an audiovisual item discovered during channel feed polling before full ingestion. | `VideoItem`, `FeedEntry`, `MediaMeta` |
| **`ChannelFeedQuery`** | Value Object / Command DTO | Encapsulates query constraints (`channel_url`, `lookback_days`, `max_videos`) for discovering uningested media items without leaking infrastructure storage details. | `FeedQuery`, `ChannelRequest`, `SyncCriteria` |
| **`PipelineStatus`** | Value Object / Enumeration | Enumerated execution outcome classification (`COMPLETED`, `SKIPPED_IDEMPOTENT`, `QUARANTINED`, `FAILED_INGESTION`, `FAILED_TRANSFORMATION`) enabling resilient batch processing and granular reporting without unhandled runtime exceptions. | `ExecutionState`, `RunResult`, `StatusFlag` |
| **`SyncSummary`** | Value Object | Immutable batch execution report aggregating total discovered items, processed count, skipped idempotency count, failed count, and execution duration. | `BatchReport`, `ChannelSyncResult`, `RunMetrics` |
| **`LedgerEntry`** | Value Object | Immutable transactional audit and idempotency record (`content_id`, `media_url`, `title`, `channel_name`, `status`, `notes_count`, `error_message`, `started_at`, `completed_at`) persisted in the SQLite WAL ledger. | `LedgerRecord`, `AuditEntry`, `HistoryRow` |
| **`SyncFilterCriteria`** | Value Object | Immutable multi-criteria domain filter encapsulating sanitized tuples of target channels, taxonomy categories (evaluating domain vs volatility classes), and discrete video IDs. | `FilterParams`, `SyncFilter`, `FeedFilter` |
| **`AlphabeticalFeedOrdering`** | Domain Invariant | Deterministic sorting rule mandating that all candidate channel feeds discovered from manifests or lakes are ordered alphabetically case-insensitively before feed probing or media downloads. | `AlphabeticalSync`, `SortedChannels`, `DeterministicOrder` |
| **`ChannelName`** | Value Object | Immutable, self-validating identifier representing a content creator or channel feed. Enforces non-emptiness, trims whitespace, caps length at 120 chars, and rejects path traversal sequences (`..`, `/`, `\`). Supports transparent string equality and hashing. | `channel_str`, `channel_id`, `chan_name`, `ch_name`, `cn` |
| **`SourceModality`** | Value Object / Enumeration | Strongly-typed enumeration (`FILE = "file"`, `URL = "url"`) representing the physical or remote ingestion modality of a batch source item, replacing unvalidated string primitives. | `kind_str`, `source_type`, `input_kind` |
| **`TokenHash`** | Value Object | Immutable, self-validating cryptographic SHA-256 hash enforcing exactly 64 lowercase hexadecimal characters for Personal Access Tokens and secrets per ADR-048. | `raw_hash`, `token_str`, `hash_key` |
| **`PersonalAccessToken`** | Entity / Aggregate | Domain entity for machine-to-machine authentication supporting clock-injectable validity verification (`is_active_at`), permission scopes, and usage audit timestamps per ADR-018 and ADR-048. | `PAT`, `api_key`, `access_token` |
| **`PromptSpec.description`** | Canonical SSOT Field | Canonical textual specification of a prompt's synthesis responsibility and architectural role in `PromptCatalog` (`prompts.json`), replacing deprecated `PromptMetadata.description` in `PROMPT_REGISTRY` per ADR-050 and ADR-052. | `task`, `task_description`, `prompt_goal`, `PromptMetadata.description` |

## 2. Architectural & Infrastructure Terms

| Canonical Term | Definition | Aliases to AVOID |

| **`StageTranscriptPersistence`** | Canonical infrastructure pattern in `VaultRepositoryPort` and `TranscriptVaultHandler` for storing stage envelopes at `data/{stage}/{channel_name}/{content_id}.md` with monomorphic YAML frontmatter, dynamic stage directory resolution, and elimination of legacy method variants per ADR-058 and ADR-059. | `FolderSwitch`, `TranscriptsStorage`, `HardcodedStageDirs`, `save_transcript` |
| **`EvalRubric`** | Quantified scoring criteria (faithfulness, relevance, hallucination, toxicity) executed via Langfuse to validate LLM output quality against frozen thresholds. | `PromptTest`, `QualityCheck`, `EvalSpec` |

| **`ComputeBudgetPolicy`** | Dynamic resource governance policy that calculates and constrains worker concurrency based on available CPU cores and GPU VRAM headroom, preventing system OOM, device contention, and external API throttling. | `WorkerLimit`, `ConcurrencySetting`, `ResourceCap` |

| **`ResilientTransportPolicy`** | Infrastructure network policy configured at the Composition Root governing HTTP connection pooling (Keep-Alive), granular TCP socket timeouts (`connect`, `read`, `write`, `pool`), and exponential backoff retries with jitter via `tenacity`. | `HttpSettings`, `NetworkConfig`, `RetryPolicy` |
| **`CresmoInfrastructureError`** | Base exception for infrastructure adapter failures (network timeouts, HTTP 429 rate limits, disk I/O, subprocess crashes), segregated completely from business invariant violations in the pure domain core. | `AdapterError`, `SystemError`, `IoException` |
| **`SyncChannelUseCase`** | Application orchestrator coordinating feed polling, lookback filtering, ledger idempotency checks, and bounded worker dispatching for channel media feeds, consuming `CresmoPipeline` for single-item synthesis. | `ChannelSynchronizer`, `FeedBatchRunner`, `ChannelWatcher` |
| **`PreflightHealthChecker`** | Bootstrap diagnostic service that verifies environmental invariants (credentials presence, system binary dependencies like `ffmpeg`, and storage write permissions) in <10ms before allowing resource-intensive I/O pipelines to start. | `StartupValidator`, `EnvCheck`, `SanityGuard` |
| **`LazyCommandGroup`** | Presentation Click/Typer dispatching construct that resolves and loads subcommand modules strictly on demand when a matching subcommand is invoked, preserving CLI help and command parsing without importing the full application dependency tree per ADR-055. | `DynamicTyperGroup`, `SubcommandLoader`, `LazyDispatcher` |
| **`ZeroReadMetadataExtraction`** | Discovery optimization extracting entity identifiers (`video_id`) and creator provenance (`channel_name`) directly from filesystem path semantics (`<Channel>/<ContentId>.md`) without opening or reading the file contents from disk per ADR-055. | `PathOnlyInspection`, `ZeroIoExtraction`, `StatlessDiscovery` |
| **`DeferredAdapterInitialization`** | Architectural pattern deferring infrastructure resource initialization (e.g. SQLite DDL/PRAGMA execution, YAML/JSON catalog loading, SDK network clients) from adapter construction (`__init__`) to first transactional use per ADR-055. | `LazyAdapterInit`, `OnDemandResourceBinding`, `JustInTimeInit` |
