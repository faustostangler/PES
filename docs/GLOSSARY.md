# Ubiquitous Language Glossary — PES Strategic Knowledge Monolith

This glossary establishes the canonical terminology across all engineering discussions, code identifiers, comments, documentation, and tests for the PES workspace.

---

## 1. Domain Entities & Value Objects

| Canonical Term | Pronunciation / Context | Definition | Aliases to AVOID |
|---|---|---|---|
| **`ContentId`** | Value Object | Strongly-typed unique identifier for a raw media item or transcript, derived from video ID or content hash. Enforces non-empty string and regex validation. | `id`, `video_id_str`, `raw_id` |
| **`NoteTitle`** | Value Object | Validated canonical title of an Atomic Note, automatically sanitized of `[[` brackets, path characters, and trailing whitespace. | `title_str`, `name`, `clean_title` |
| **`NoteType`** | Value Object | Enumerated typology classification restricted to: `concept`, `entity`, `event`, or `process`. | `tag_type`, `category`, `kind` |
| **`CausalMatrix`** | Value Object | Immutable ternary attribution model defining `cause` (underlying premise), `effect` (observable outcome), and `epistemic_attribution` (origin author/school). | `matrix`, `causality`, `premise_pair` |
| **`CrossContextRelations`** | Value Object | Immutable triad connecting a concept to its historical `precursors`, synchronous `lateral_events`, and systemic `aftermath`. | `context_net`, `network_links`, `relations` |
| **`RawTranscript`** | Entity / Aggregate | Unmodified, verbatim text of spoken audio extracted from media feeds, carrying immutable origin metadata. | `raw_text`, `transcript_dump`, `audio_text` |
| **`EnrichedCompendium`** | Entity / Aggregate | Continuous, dense, multi-pass factual prose document generated from a Raw Transcript without bullet lists or tables, containing a mandatory `Informações Complementares` section. | `article`, `expanded_text`, `summary`, `draft` |
| **`AtomicNote`** | Entity / Aggregate | A self-contained, highly-focused semantic unit in the Second Brain vault representing a single concept, entity, event, or process with standardized frontmatter, definition, WikiLinks, causal matrix, and cross-context links. | `note`, `card`, `wiki_page`, `markdown_file` |
| **`MapOfContent` (MOC)** | Entity / Aggregate | Navigational and conceptual synthesis document that groups and reconciles a thematic cluster of Atomic Notes with bidirectional links, ensuring zero orphaned notes. | `hub`, `index_page`, `toc`, `table_of_contents` |
| **`AtomicEntityInventory`** | Value Object | Deduplicated discovery manifest of distinct entities, concepts, events, and processes discovered across an Enriched Compendium prior to batch note generation. | `candidate_list`, `topics`, `tag_candidates` |
| **`DiscoveredMediaItem`** | Value Object | Immutable metadata descriptor (`content_id`, `title`, `published_at`, `media_url`) representing an audiovisual item discovered during channel feed polling before full ingestion. | `VideoItem`, `FeedEntry`, `MediaMeta` |
| **`ChannelFeedQuery`** | Value Object / Command DTO | Encapsulates query constraints (`channel_url`, `lookback_days`, `max_videos`) for discovering uningested media items without leaking infrastructure storage details. | `FeedQuery`, `ChannelRequest`, `SyncCriteria` |
| **`PipelineStatus`** | Value Object / Enumeration | Enumerated execution outcome classification (`COMPLETED`, `SKIPPED_IDEMPOTENT`, `FAILED_INGESTION`, `FAILED_TRANSFORMATION`) enabling resilient batch processing and granular reporting without unhandled runtime exceptions. | `ExecutionState`, `RunResult`, `StatusFlag` |
| **`SyncSummary`** | Value Object | Immutable batch execution report aggregating total discovered items, processed count, skipped idempotency count, failed count, and execution duration. | `BatchReport`, `ChannelSyncResult`, `RunMetrics` |
| **`LedgerEntry`** | Value Object | Immutable transactional audit and idempotency record (`content_id`, `media_url`, `title`, `channel_name`, `status`, `notes_count`, `error_message`, `started_at`, `completed_at`) persisted in the SQLite WAL ledger. | `LedgerRecord`, `AuditEntry`, `HistoryRow` |

## 2. Architectural & Infrastructure Terms

| Canonical Term | Definition | Aliases to AVOID |
|---|---|---|
| **`MediaIngestionPort`** | Abstract application interface defining contracts for crawling, downloading subtitles, and transcribing audiovisual media. | `ScraperInterface`, `DownloaderPort` |
| **`LLMTransformationPort`** | Abstract application interface defining contracts for deterministic text generation, inventory discovery, and batched note synthesis. | `AIPort`, `ModelService`, `GenaiPort` |
| **`VaultRepositoryPort`** | Abstract application interface defining contracts for reading, writing, and indexing atomic notes, compendiums, and MOCs in the Second Brain vault. | `FileStoragePort`, `WikiStorage`, `DbPort` |
| **`LedgerRepositoryPort`** | Abstract application interface defining contracts for querying and updating processed media content IDs. | `LogPort`, `HistoryPort`, `TrackingPort` |
| **`LegacyISBMediaIngestionAdapter`** | Anti-Corruption Layer (ACL) that encloses legacy code in `playground/isb.ai/`, isolating `sys.path` modifications and converting legacy dictionaries into domain entities. | `ISBWrapper`, `SyncHelper` |
| **`ObsidianVaultAdapter`** | Infrastructure adapter implementing `VaultRepositoryPort` using atomic `.tmp` rename filesystem operations and frontmatter serialization. | `MarkdownWriter`, `WikiAdapter` |
| **`EvalRubric`** | Quantified scoring criteria (faithfulness, relevance, hallucination, toxicity) executed via Langfuse to validate LLM output quality against frozen thresholds. | `PromptTest`, `QualityCheck`, `EvalSpec` |
| **`CompositionRoot`** | Centralized presentation layer entrypoint where infrastructure adapters are instantiated, configuration is bound, and dependencies are injected into application orchestrators. | `MainFactory`, `Bootstrapper`, `WireContainer` |
| **`HumbleObjectCLI`** | Architectural presentation pattern ensuring command-line interfaces remain ultra-thin translators between I/O streams/flags and use cases with zero domain logic. | `CommandLineScript`, `RunnerScript`, `GodCLI` |
| **`SqliteLedgerAdapter`** | Infrastructure adapter implementing `LedgerRepositoryPort` using SQLite in Write-Ahead Logging (`PRAGMA journal_mode=WAL;`) and `PRAGMA synchronous=NORMAL;` to guarantee concurrent multi-process ACID transactions and crash-resilient idempotency tracking without file lock contention. (Replaces `JsonLedgerAdapter`). | `JsonLedgerAdapter`, `DatabaseLedger`, `SqliteAudit` |
| **`ComputeBudgetPolicy`** | Dynamic resource governance policy that calculates and constrains worker concurrency based on available CPU cores and GPU VRAM headroom, preventing system OOM, device contention, and external API throttling. | `WorkerLimit`, `ConcurrencySetting`, `ResourceCap` |
| **`ScratchStorageService`** | Infrastructure service managing the lifecycle of temporary media assets (audio/subtitles) on dedicated disk partitions using RAII context managers, POSIX signal cleanup traps (`SIGINT`/`SIGTERM`), and cold-start orphan hygiene to prevent `tmpfs`/RAM saturation and `ENOSPC` errors. | `TempFileManager`, `ScratchCleaner`, `DiskBuffer` |
| **`ResilientTransportPolicy`** | Infrastructure network policy configured at the Composition Root governing HTTP connection pooling (Keep-Alive), granular TCP socket timeouts (`connect`, `read`, `write`, `pool`), and exponential backoff retries with jitter via `tenacity`. | `HttpSettings`, `NetworkConfig`, `RetryPolicy` |
| **`CresmoInfrastructureError`** | Base exception for infrastructure adapter failures (network timeouts, HTTP 429 rate limits, disk I/O, subprocess crashes), segregated completely from business invariant violations in the pure domain core. | `AdapterError`, `SystemError`, `IoException` |
| **`SyncChannelUseCase`** | Application orchestrator coordinating feed polling, lookback filtering, ledger idempotency checks, and bounded worker dispatching for channel media feeds, consuming `CresmoPipeline` for single-item synthesis. | `ChannelSynchronizer`, `FeedBatchRunner`, `ChannelWatcher` |
| **`PreflightHealthChecker`** | Bootstrap diagnostic service that verifies environmental invariants (credentials presence, system binary dependencies like `ffmpeg`, and storage write permissions) in <10ms before allowing resource-intensive I/O pipelines to start. | `StartupValidator`, `EnvCheck`, `SanityGuard` |
| **`StageCheckpointPolicy`** | Application checkpointing strategy that queries `VaultRepositoryPort` for existing intermediate artifacts (`raw`, `enriched`) before re-invoking LLM inference, enabling instant resume-from-crash and token economy unless overridden by `--force-refresh`. | `ArtifactCache`, `PipelineCheckpoint`, `IntermediateStore` |
| **`BatchQueueOrchestrator`** | Application service managing priority-tiered scheduling (`HIGH` priority pre-empting `STANDARD` channel feeds) for discovered media items, ensuring critical tasks drain immediately without head-of-line blocking. | `PriorityScheduler`, `ItemDispatcher`, `FeedQueue` |
| **`MultiRoleContainer`** | Single Source of Truth (SSOT) container packaging utilizing a multi-stage Debian-slim runtime with `uv` to manifest CLI, Scraper Worker, or API roles identically from a single image without code divergence. | `AppContainer`, `DockerImage`, `UnifiedImage` |
| **`EntrypointDispatcher`** | Container bootstrap script routing process execution according to the active role (`api`, `worker`, or `cli`), applying signal traps (`SIGINT`/`SIGTERM`) and invoking child processes with `exec` for proper PID 1 signal forwarding. | `DockerEntrypoint`, `RoleRouter`, `ContainerInit` |
| **`ProcessSupervisor`** | Container init wrapper (`tini`) operating as PID 1 to reap zombie child processes (spawned by media tools like `ffmpeg` or `yt-dlp`) and forward termination signals (`SIGTERM`/`SIGINT`) cleanly to the application runtime. | `TiniSupervisor`, `InitProcess`, `ZombieReaper` |
| **`VolumeTopology`** | Segregated storage architecture in container orchestration isolating persistent note storage (Obsidian Vault), relational database state (SQLite WAL with local POSIX locking), and ephemeral scratch disks with host UID/GID permission alignment. | `StorageLayout`, `MountStrategy`, `VolumeLayout` |
| **`ContainerResourceGovernance`** | Infrastructure deployment policy enforcing deterministic cgroups v2 resource limits (`cpus`, `memory`) in orchestration manifests to prevent OOM killer events and CPU starvation. | `ResourceLimits`, `CgroupLimits`, `ContainerBudget` |
| **`HeartbeatHealthCheck`** | Background worker liveness probe updating an atomic heartbeat timestamp file (`/tmp/cresmo_worker.heartbeat`) allowing the container runtime to detect silent deadlocks and perform automated self-healing. | `WorkerLivenessProbe`, `HeartbeatWatchdog`, `LivenessProbe` |
| **`InferenceProfile`** | Domain value object defining cognitive inference parameters (`temperature`, `top_p`, `seed`, `response_mime_type`, `response_schema`) instructing adapters how to execute LLM calls without coupling domain code to vendor SDKs. | `SamplingConfig`, `LLMParams`, `ModelProfile` |
| **`TwoPhaseAtomicSynthesis`** | Application orchestration pattern decoupling massive extraction (100–150+ notes) into a global holistic inventory indexing phase (`DiscoverAtomicInventoryUseCase`) followed by chunked, schema-constrained retrieval batches of $\le 5$ notes (`SynthesizeAtomicBatchUseCase`) to prevent context window overflow and output token exhaustion. | `BatchedSynthesis`, `ChunkedExtraction`, `InventoryWorkflow` |
| **`ThreeLayerGuardrails`** | Multi-tier AI safety architecture combining structural input quarantine, in-flight negative prompt constraints, and asynchronous/sampled Langfuse LLM-as-a-judge quality evaluations (EVAL-001) to eliminate prompt injections and hallucination without doubling pipeline latency. | `SafetyGuardrails`, `EvalGuardrails`, `DefenseInDepthAI` |
| **`UntrustedContentQuarantine`** | Structural sanitization technique isolating third-party audio transcripts within strict XML boundary tags (`<untrusted_source_transcript>`) alongside parser instructions prohibiting prompt overrides and malicious code injection. | `InputSanitization`, `ContentIsolation`, `PromptQuarantine` |
| **`FasterWhisperEngine`** | Infrastructure speech-to-text Deep Learning engine using CTranslate2 C++ inference runtime with INT8/FP16 quantization and integrated Silero VAD to eliminate silence hallucination loops and accelerate local transcription up to $4\times$. | `WhisperRuntime`, `AudioTranscriber`, `SpeechToTextAdapter` |
| **`VoiceActivityFilter`** | Audio pre-processing filter (Silero VAD) identifying and extracting human speech segments prior to transformer encoding, preventing silence and background musical repetition artifacts. | `VadFilter`, `SileroVad`, `SpeechDetector` |
| **`HierarchicalThematicEnrichment`** | Application pipeline pattern for processing long transcripts (>10,000 words) using a three-pass strategy (Thematic Outline Scan $\rightarrow$ Sectional Deep Expansion $\rightarrow$ Compendium Stitching) to overcome the 8,192 output token limit and eliminate Attention Sinks ("Lost in the Middle"). | `ThematicEnricher`, `SectionalExpander`, `LongFormProcessor` |
| **`ThematicOutline`** | Domain value object representing semantic thematic acts/chapters with timestamps, core arguments, and transitional links across long-form audio transcripts. | `LectureOutline`, `ThematicSkeleton`, `ChapterMap` |
| **`LLMAdapterFactory`** | Infrastructure factory service located in the Composition Root responsible for instantiating and wiring the active `LLMTransformationPort` implementation (`GeminiLLMAdapter`, `OllamaLLMAdapter`, or `MockLLMAdapter`) based on Pydantic environment configuration. | `ModelFactory`, `ProviderResolver`, `LLMProviderFactory` |
| **`OllamaLLMAdapter`** | Secondary infrastructure adapter implementing `LLMTransformationPort` via HTTP calls (`httpx`) to local OpenAI-compatible or Ollama endpoints, enabling fully offline, local-first synthesis without cloud dependencies. | `LocalLLMAdapter`, `OpenAICompatibleAdapter`, `OfflineModelAdapter` |
| **`PromptRepositoryPort`** | Abstract application port defining contracts for retrieving system and user prompt templates by slug, pipeline stage, and version tag, decoupling prompt lifecycle and prompt engineering from application orchestrators. | `PromptService`, `PromptStore`, `TemplatePort` |
| **`PromptTemplate`** | Domain value object encapsulating compiled template text, expected parameter variables, rendering logic, and provenance metadata (Langfuse commit ID or local Git SHA/file path). | `CompiledPrompt`, `TemplateObject`, `PromptString` |
| **`LangfusePromptAdapter`** | Infrastructure adapter implementing `PromptRepositoryPort` backed by Langfuse's remote managed Prompt Registry with in-memory TTL caching and graceful fallback on network errors. | `RemotePromptAdapter`, `LangfuseRegistry`, `CloudPromptAdapter` |
| **`LocalFilesystemPromptAdapter`** | Zero-dependency infrastructure adapter implementing `PromptRepositoryPort` loading version-controlled Jinja/Markdown prompt files directly from repository storage (`prompts/*.md`), guaranteeing offline-first resilience and reproducible local runs. | `FilePromptAdapter`, `StaticPromptStore`, `LocalPromptRegistry` |
| **`TraceContext`** | Domain/Infrastructure value object propagated via Python `contextvars` carrying execution lineage (`trace_id`, `session_id` bound to `ContentId`, `stage_name`, and metadata tags) across async boundaries without leaking telemetry SDKs into domain use cases. | `TracingMetadata`, `SpanContext`, `TelemetrySession` |
| **`TracingLLMTransformationDecorator`** | Infrastructure decorator wrapping `LLMTransformationPort` that intercepts cognitive inference requests to record spans, generations, token usage, latency, and prompt links into Langfuse with fail-silent resilience. | `LangfuseTraceWrapper`, `TelemetryInterceptor`, `LLMTracer` |
| **`GoldenDataset`** | Versioned benchmark collection of canonical transcripts, gold-standard compendiums, and human-verified atomic notes used for offline prompt regression testing and CI/CD quality gate enforcement against EVAL-001 rubrics. | `EvalDataset`, `BenchmarkSet`, `GroundTruthDataset` |
| **`SampledEvalWorker`** | Asynchronous background evaluation runner that selects stochastic samples of outputs from production runs (e.g., compendium + 3 to 5 atomic notes) to evaluate EVAL-001 metrics against Langfuse, detecting quality drift without increasing runtime latency. | `AsyncEvaluator`, `JudgeWorker`, `BackgroundAuditor` |
| **`DeterministicCognitivePipeline`** | Application orchestration pattern structuring AI reasoning into an explicit, typed sequence of domain use cases (`FillGapsFluidProseUseCase` $\rightarrow$ `DiscoverAtomicInventoryUseCase` $\rightarrow$ `SynthesizeAtomicBatchUseCase` $\rightarrow$ `ReconcileMocUseCase`) with stage checkpoints and strict contracts, replacing non-deterministic autonomous agent loops. | `AgentSwarm`, `AutonomousWorkflow`, `ReActPipeline` |
| **`CognitiveStage`** | Domain/Application enumeration defining explicit lifecycle phases (`TRANSCRIPTION`, `THEMATIC_ENRICHMENT`, `INVENTORY_DISCOVERY`, `BATCH_SYNTHESIS`, `MOC_RECONCILIATION`) for checkpointing and idempotent resumption. | `PipelinePhase`, `WorkflowStep`, `ProcessingStage` |
| **`SectionalContextSlicing`** | Context composition strategy during batched note synthesis that injects global thesis metadata, specific thematic chapters relevant to the 5 entities in the batch, and the full inventory title catalog, reducing input prompt tokens by 80–90% while eliminating attention degradation. | `ContextDistillation`, `PromptPruning`, `ThematicChunking` |
| **`ThematicSectionAnchor`** | Value object mapping an entity or concept in the `AtomicEntityInventory` to the specific chapter or section of the `EnrichedCompendium` where its causal mechanics and core arguments are articulated. | `SectionRef`, `ChapterLink`, `ThematicPointer` |
| **`ChannelPollingDaemon`** | Background worker service executing a non-blocking `asyncio` event loop that periodically polls channel feeds via `MediaIngestionPort`, checks idempotency via `SqliteLedgerAdapter`, enqueues new items into `BatchQueueOrchestrator`, updates `HeartbeatHealthCheck`, and applies adaptive backoff. | `FeedScheduler`, `BackgroundPoller`, `ChannelCronService` |
| **`MultiStageCIPipeline`** | GitHub Actions CI architecture organized into parallel fast-feedback jobs (lint, strict mypy, security audits), mirrored TDD unit/integration test gates with coverage enforcement, and conditional deep quality gates (mutmut mutation testing, Golden Dataset prompt evals, and Trivy OCI scans). | `BuildPipeline`, `GitHubWorkflow`, `ContinuousIntegration` |
| **`QualityGate`** | Hard automated verification threshold enforced in the CI/CD pipeline (zero lint errors, zero strict typing violations, $\ge 85\%$ test coverage, zero critical CVEs, and EVAL-001 regression baseline compliance) that halts releases upon regression. | `ValidationGate`, `MergeCheck`, `QualityBarrier` |
| **`SecretGovernancePolicy`** | Configuration security policy encapsulating all API keys and tokens in `pydantic.SecretStr`, supporting both environment variables and Docker secret files (`/run/secrets/*`), and guaranteeing zero plaintext leakage in logs, stack traces, or OCI inspect metadata. | `SecretManager`, `KeyManager`, `CredentialsPolicy` |
| **`RootlessContainerHardening`** | Container runtime security posture enforcing non-root execution (`appuser:10001`), read-only root filesystem (`read_only: true`), dropping all Linux capabilities (`cap_drop: [ALL]`), and preventing privilege escalation (`no-new-privileges: true`). | `ContainerSecurity`, `PodHardening`, `DockerHardening` |
| **`VaultSandboxIsolation`** | Filesystem security boundary enforced within `ObsidianVaultAdapter` resolving canonical absolute paths (`Path.resolve()`) and requiring `path.is_relative_to(vault_root.resolve())` before any file write, mathematically preventing path traversal and arbitrary filesystem overwrite. | `VaultJail`, `PathTraversalGuard`, `VaultSanitizer` |
| **`SecurityViolationError`** | Infrastructure exception raised immediately when a security boundary violation occurs (path traversal attempt, shell injection character, or sandbox escape attempt), triggering immediate pipeline abort and audit logging. | `PathTraversalError`, `SecurityAlert`, `AccessDeniedError` |
| **`PrometheusGoldenSignals`** | SRE infrastructure telemetry instrumentation exposing standard golden signals (latency, traffic, error rates, and saturation gauges) via Prometheus HTTP `/metrics` endpoint for real-time node and container reliability alerting. | `InfraMetrics`, `SystemTelemetry`, `ServiceHealthMetrics` |
| **`DomainBusinessMetrics`** | Domain-aligned telemetry tracking business outcomes in Ubiquitous Language (note creation throughput by typology, EVAL-001 quality score distributions, synthesis acceleration ratio, and idempotency hit rates). | `BusinessMetrics`, `AppMetrics`, `DomainCounters` |
| **`StructuredJsonLogging`** | 12-Factor App telemetry pattern emitting structured newline-delimited JSON events to `stdout` (`timestamp`, `level`, `logger`, `event`, `content_id`, `trace_id`, `stage_name`, `elapsed_ms`), ingested natively by Docker and Grafana Loki without brittle regex. | `JsonLogger`, `LokiLogging`, `ConsoleLogger` |
| **`TraceCorrelation`** | Cross-platform observability linkage pattern binding the canonical `trace_id` (`cresmo-{content_id}`) across Prometheus metric exemplars, Grafana Loki log streams, Langfuse LLM generation traces, and Sentry incident breadcrumbs. | `TraceIdLinkage`, `ObservabilityCorrelation`, `UnifiedTraceId` |
| **`HardwareAccelerationPolicy`** | Adaptive infrastructure policy evaluated during startup by `PreflightHealthChecker` that dynamically probes GPU drivers, CUDA runtime, and available VRAM to select the optimal compute target (`cuda` with `float16` vs. graceful fallback to multi-core `cpu` with `int8` quantization), guaranteeing zero-crash execution across heterogeneous environments. | `DeviceSelector`, `CudaPolicy`, `GpuAllocationPolicy` |
| **`InferenceCostGovernancePolicy`** | FinOps governance policy providing predictive pre-execution token/cost estimations, enforcing a configurable run budget ceiling (`MAX_RUN_BUDGET_USD`) with clean transaction completion and paused state tracking in SQLite WAL, and supporting cognitive model right-sizing (flash/local models for inventory discovery and batched note synthesis vs. deep reasoning models for compendiums and MOCs). | `CostManager`, `BudgetGuard`, `FinOpsPolicy` |
