A diferença entre Git, GitHub, GitLab e SourceTree para iniciantes em tecnologia. Então, o Git é como uma máquina do tempo para o seu computador. É um sistema de controle de versão de código onde cada alteração feita é salva, permitindo que você reverta o processo caso algo dê errado. E depois de terminar de usar o Git localmente, você acessa o GitHub, que funciona como um Google Drive para o seu código. Basicamente, você pode compartilhar isso com outras pessoas. O GitLab chega e eleva tudo a um novo

patamar. Ele não apenas compartilha seu código, mas também automatiza testes e a compilação. E isso é realmente usado em muitas grandes empresas de tecnologia. E, por fim, o Source Tree é para preguiçosos como você. Se você não quer ter que digitar comandos git complicados e lidar com branches e processos de merge, o SourceTree é como uma interface gráfica amigável que cuida de tudo isso.
