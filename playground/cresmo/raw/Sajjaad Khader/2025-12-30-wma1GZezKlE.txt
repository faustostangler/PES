Stop wasting your time on tech interview prep and instead master these four algorithms. First is BFS or breath first search. BFS explores everything closest to you first level by level. It guarantees the shortest path but uses more memory as the search base grows. Next we got DFS or depth for search. DFS

goes as deep as possible down one path before backing up. It uses very little memory but does not guarantee the shortest path. Third, we got dystras. This is your shortest path in a weighted graph algorithm. It almost always gets the optimal path, but it can be slow since it explores many possibilities.

Number four, we got AAR. This combines Dyster's shortest path algorithm with a guess of the distance that's left. It's called a heristic, and it's used in Google Maps because things like weather and traffic can affect which route is optimal to take. And now follow for more tech content.
