  O Kombai é um agente especializado em frontend, e o Design Mode é o módulo de geração visual dentro dele. Você abre a extensão no VS Code, seleciona Design no mode dropdown, e tem acesso a uma canvas onde a IA gera UI a partir de prompt em linguagem natural, com 5 conceitos centrais: Canvas, Themes, Blocks, Style Guides e CSS Editor.
  
  O recurso que mais impressiona é a Inspiration Library. Ao invés de descrever do zero como quer a UI, você abre a biblioteca de inspirações, navega por sites de referência reais (estilo Linear, Raycast, Vercel) e copia o style guide direto pro Design Mode. A IA absorve a vibe visual, paleta, tipografia, espaçamento, e aplica em tudo que gerar dali pra frente. Tem também a Style Guides Gallery pra quem prefere escolher uma vibe pronta.
  
  Depois do prompt inicial vem o ciclo de refinement passes automáticos. A IA não cospe uma versão e para. Ela gera, avalia, ajusta, refina, faz vários passes ajustando hierarquia visual, espaçamento, contraste e detalhes que normalmente exigiriam round de feedback humano.
  
  Quando o design tá pronto, você edita direto na canvas: seleciona qualquer elemento e altera por linguagem natural ou edição visual. Quer mudar headline? Seleciona e digita. Quer cards mais compactos com hover sutil? Descreve. Sem abrir CSS no editor.
  
  O segredo da consistência multi-tela é o design system reuse. Você gera a landing page, define o sistema visual, e nas próximas telas o Kombai aplica o MESMO design system automaticamente. Cores, tipografia, estilo de botão, espaçamento, tudo bate.
  
  Quando o design tá fechado, troca pro Plan Mode. O Kombai recebe os designs e gera um plano editável com Design Plan, Technical Implementation e To-dos, antes de tocar em código. Esse é o diferencial de agente especializado: pensa como dev antes de executar.
  
  Aprovado o plano, entra o Code Mode. Aqui o Kombai executa o To-do, criando arquivos com Context Graphs (que mostram reuso de componentes entre telas) e Working Set visível.
  
  A stack final do projeto demo é Next.js 15 com App Router, TypeScript, Tailwind, shadcn/ui, Better-auth com SQLite local, e separação clara entre rota pública e rota protegida. Tudo gerado a partir dos designs.
