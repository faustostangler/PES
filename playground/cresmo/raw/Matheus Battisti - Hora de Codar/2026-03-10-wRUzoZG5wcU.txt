  O problema que motivou o lançamento: a produção de código por engenheiro na Anthropic cresceu 200% no último ano. Com ferramentas como Claude Code, Cursor e Codex, os devs tão produzindo código numa velocidade absurda. Mas quem revisa tudo isso? Antes de lançar esse sistema só 16% dos PRs da Anthropic recebiam feedback substancial. O resto era basicamente um carimbo de aprovado.
  
  O Code Review é um sistema multi-agente que roda automaticamente quando um PR é aberto no GitHub. Quando o PR abre o sistema despacha múltiplos agentes especializados que trabalham em paralelo. Cada agente olha pra tipos diferentes de problemas: erros de lógica, vulnerabilidades de segurança, edge cases quebrados, regressões sutis. Depois os agentes verificam os achados uns dos outros pra filtrar falsos positivos. Um agente final agrega tudo, remove duplicatas e ordena por gravidade. O resultado aparece como comentário resumo no PR com comentários inline nas linhas exatas onde tem problema, com explicação de por que é um problema e sugestão de fix.
  
  Os números internos da Anthropic são impressionantes. Antes 16% dos PRs recebiam comentários substanciais, depois subiu pra 54%. PRs grandes com mais de mil linhas: 84% recebem achados com média de 7.5 issues. Taxa de falso positivo: menos de 1% dos achados são marcados como incorretos pelos engenheiros. Tempo médio de 20 minutos por review. A Cat Wu, head de produto do Claude Code, disse que decidiram focar puramente em erros lógicos. Nada de estilo de código ou coisas que um linter pega.
  
  Dois casos reais que a Anthropic compartilhou. O primeiro: uma mudança de uma linha num serviço de produção ia quebrar o mecanismo de autenticação inteiro. Parecia inofensiva. Um humano provavelmente aprovaria sem pensar. O Code Review pegou e classificou como crítico. O segundo: a TrueNAS tava fazendo refactoring de criptografia ZFS e o Code Review encontrou um bug em código adjacente onde um type mismatch poderia apagar o cache de chaves de criptografia. E tem o caso do Firefox: o Claude Opus 4.6 escaneou o codebase inteiro e encontrou 22 vulnerabilidades em duas semanas.
  
  O preço: entre 15 e 25 dólares por review dependendo da complexidade. É caro comparado com CodeRabbit que cobra 24 por mês. Mas a Anthropic posiciona como seguro, não como produtividade. Pra equipes onde um bug escapar custa caro de verdade. Disponível em research preview pra planos Teams e Enterprise.
  
  Pra quem não tem plano Teams ou Enterprise tem outra opção. O Claude Code tem um plugin open source de code review que roda local no terminal. É o comando /code-review. Lança 4 agentes em paralelo, pontua cada issue por confiança e mostra issues com score acima de 80. Não é tão completo quanto o serviço gerenciado mas funciona pra quem usa Claude Code individual.
  
  O contexto maior: a Anthropic lançou tudo isso no que pode ser o dia mais importante da história da empresa. A Anthropic tá dobrando a aposta no enterprise.
