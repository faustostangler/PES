  Se você já testou Hermes Agent no terminal e achou poderoso mas pouco acessível, ou se quer um companion visual pra rodar agente IA self-hosted com memória persistente, esse vídeo é pra você. O Hermes Desktop é um projeto da comunidade (feito pelo fathah, não oficial Nous Research) que usa por baixo o instalador oficial do Hermes Agent. Ele resolve a parte de UX que faltava: chat com SSE streaming, tela de memória, tela de skills, tela de tools, configuração de providers tudo em interface visual.
  
  A instalação é direta. Baixa a release do GitHub do fathah, abre o app e cai na tela inicial Local or Remote. Seleciona LOCAL e o instalador automático detecta Git, uv e Python 3.11+, baixando o que falta. Em seguida aparece a tela de escolha de provider: tem 11 disponíveis, e no vídeo uso OpenRouter com Claude Opus 4.6. Cola a API key e o workspace abre pronto.
  
  A primeira parte é o tour de features. Mostro o chat com streaming e rodo os slash commands principais: /tools pra ver toolsets disponíveis, /skills pra ver skills carregadas, /memory pra inspecionar memória persistente, e /model pra trocar de modelo na hora. Cada tela tem visualização própria, sem precisar abrir arquivo ou rodar comando externo. Por baixo segue sendo o Hermes Agent oficial, com 22 slash commands, 16 messaging gateways, 14 toolsets, 7 terminal backends e MIT License. O Desktop é a camada visual, o motor continua o mesmo.
  
  O teste prático é uma skill self-improving: peço pro agente criar uma skill que monitora os 5 maiores canais brasileiros de IA no YouTube e me avisa quando algum publicar vídeo novo. Em segundos a skill é gerada, aparece na tela de Skills e fica disponível pra prompt natural.
  
  Aqui vem o pivot do vídeo e o motivo de existir um Desktop App separado. Fecho o notebook e o agente para. Task incompleta. Esse é o problema que 99% dos tutoriais de agente IA ignora: PC desligado significa agente desligado. O Hermes Desktop resolve isso de um jeito que nenhum outro companion faz: tem um toggle Local/Remote em Settings que troca o cérebro do agente sem reinstalar nada.
  
  Pra demonstrar o modo remoto, uso uma VPS Hostinger (terminal SSH embutido no painel, sem cliente externo). Rodo o instalador oficial do Hermes Agent na VPS, configuro o mesmo provider, e subo o gateway HTTP com API key secreta. Volto no Desktop App do PC, troco o toggle pra Remote, colo URL e API key, testo conexão e pronto. Mesma interface, outro cérebro, agora na nuvem.
  
  Disparo uma task longa pelo chat: pesquisar os 10 maiores canais brasileiros de IA no YouTube, analisar títulos dos últimos 30 vídeos, identificar padrões de palavras-chave de engajamento, e mandar relatório completo. Fecho o desktop, fecho o notebook, saio pra viver. Minutos depois recebo notificação no Telegram com o relatório pronto. Respondo pelo celular pedindo detalhes de um canal, e o agente responde em segundos.
  
  Casos de uso que justificam essa arquitetura: monitoramento de concorrentes a cada hora, lead capture respondendo às 3h da manhã, automação de redes postando e respondendo DMs, research assistant entregando relatório pronto quando você acorda.
