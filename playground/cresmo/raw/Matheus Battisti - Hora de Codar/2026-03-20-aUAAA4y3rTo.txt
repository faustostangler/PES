  Todo software profissional como GIMP, Blender e LibreOffice foi feito pra humanos. Interface gráfica, menus, botões. Agentes de IA não sabem usar GUI. A alternativa hoje é Computer Use que tira screenshot, identifica botão, clica e reza pra funcionar. Lento, frágil, caro. O CLI-Anything resolve isso de outra forma: ele analisa o código-fonte de qualquer software e gera automaticamente uma CLI completa. O agente controla tudo pelo terminal com output JSON estruturado.
   
  O pipeline tem 7 fases que rodam automaticamente com um único comando: Analyze, Design, Implement, Plan Tests, Write Tests, Document e Publish. 11 softwares suportados. 1.508 testes gerados. 100% pass rate. Feito pelo HKUDS da Universidade de Hong Kong, o mesmo time por trás do LightRAG e do nanobot.
   
  Tem uma comparação importante com MCP que vale entender. O MCP era pra ser a ponte universal entre agentes e ferramentas mas na prática injeta dezenas de schemas na janela de contexto que o agente nunca usa. Os benchmarks do CLI-Anything mostram números impressionantes de economia de tokens e confiabilidade comparado com MCP. Mas não é um ou outro: o próprio Claude Code usa os dois e CLI-Anything gera CLIs que podem ser expostas via MCP se precisar.
   
  A instalação é dois comandos no marketplace do Claude Code. Depois roda um comando pra gerar a CLI pro GIMP a partir do código-fonte do software. Ele analisa, implementa, testa e documenta tudo automaticamente. Precisa ter o GIMP instalado na máquina porque ele chama o backend real do software.
   
  Na demo peço pro Claude Code criar uma thumbnail de 1280x720 usando o GIMP pelo terminal. Fundo escuro tech com gradiente, título grande centralizado, subtítulo em fonte monospace estilo código, glow no texto e exporta como PNG. Mostro cada passo sendo executado: criação do projeto, layers de background, gradiente, texto, filtros, exportação. O GIMP real processando tudo. Nenhuma janela abriu. O resultado é uma imagem gerada pelo GIMP de verdade controlado inteiramente pelo Claude Code via terminal.
   
  Mostro também o comando refine que analisa gaps na CLI gerada e implementa comandos que faltam. Incremental e não destrutivo. Se a CLI não cobrir alguma funcionalidade específica que você precisa, pede pro CLI-Anything expandir.
   
  O conceito por trás é poderoso: qualquer software com código-fonte aberto pode ser transformado em ferramenta controlável por agentes de IA. Hoje os programas servem humanos. Com CLI-Anything o Claude Code, OpenCode e Codex podem controlar GIMP, Blender, LibreOffice e mais diretamente pelo terminal.
