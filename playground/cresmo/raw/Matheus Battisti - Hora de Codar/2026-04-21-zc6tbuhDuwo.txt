  O conceito por trás do GStack é tratar IA como uma equipe, não como um assistente. O pipeline segue 7 etapas: Think, Plan, Build, Review, Test, Ship, Reflect. Cada slash command ativa um modo cognitivo diferente, como se fosse um especialista entrando na sala. São 28 slash commands e 8 power tools que transformam o Claude Code de um assistente genérico numa equipe de 20 especialistas. Funciona também com Codex, Gemini CLI e Cursor.
   
  A instalação é colar uma instrução dentro do Claude Code e ele faz tudo sozinho: clona o repo, roda o setup, configura o CLAUDE.md e registra todos os 28 skills como slash commands. Precisa de Claude Code, Git e Bun. No Windows funciona com Git Bash ou WSL e precisa ter Node.js além do Bun. Tem opção de instalar por projeto pra que o time inteiro receba quando fizer git clone.
   
  O projeto que construo é o PensaAí, uma micro-rede social de pensamentos e frases. Cadastro e login, postar pensamentos com limite de caracteres, feed público com os mais recentes primeiro, sistema de likes com um por usuário por pensamento. Stack com Next.js, SQLite, Tailwind e Shadcn/ui. Simples de entender mas com auth e banco de dados que dão margem real pro pipeline encontrar problemas.
   
  Passo por todas as etapas do pipeline. O /office-hours faz 6 perguntas que reformulam o produto como se fosse uma sessão real com sócio do YC. O /plan-ceo-review repensa o escopo com 4 modos de operação: expansão, expansão seletiva, manter escopo e redução. O /plan-eng-review trava a arquitetura técnica com diagramas, edge cases, plano de testes antes do código. Depois codo normalmente e rodo o /review que é um code reviewer sênior que encontra bugs que passam no CI mas explodem em produção.
   
  O momento mais impressionante é o /qa. Ele abre um browser Chromium real, lê o diff do git pra saber quais páginas testar, cria conta, loga, posta pensamento, verifica no feed, dá like, confere contador, faz logout e verifica persistência. Se encontra bug corrige com commit atômico, gera teste de regressão e re-verifica. Tudo sozinho. O browser roda persistente com cookies e estado mantidos entre comandos. Tem headed mode com /connect-chrome que mostra o Chrome real sendo controlado e um sidebar agent pra dar instruções em linguagem natural.
   
  O /cso roda OWASP Top 10 e STRIDE threat modeling no código com 17 exclusões de falso positivo e gate de confiança de 8/10. O /ship sincroniza com main, roda testes, audita coverage, auto-invoca /document-release que atualiza toda a documentação e abre o PR. O /retro fecha a sprint com stats por pessoa, shipping streaks e test health. O /retro global cruza análise de todos os projetos e ferramentas de IA.
   
  Mostro também features bônus: /autoplan que roda CEO, design e eng review automaticamente, /codex que pega segunda opinião do Codex CLI da OpenAI com análise cruzada entre modelos, /design-shotgun que gera múltiplas variantes de design com painel de comparação, e o sidebar agent no Chrome. Fecho com análise honesta dos pontos positivos e de atenção incluindo consumo de tokens e as críticas que o projeto recebeu.
