  O GWS CLI é uma ferramenta de linha de comando que unifica todas as APIs do Google Workspace num único lugar. Antes se você queria que um agente de IA acessasse seu Gmail precisava configurar API, OAuth, middleware. Agora é um comando: gws gmail users messages list e pronto, seus emails em JSON.
  
  O mais impressionante é que ele não tem uma lista fixa de comandos. Ele lê o Discovery Service do Google em tempo real e constrói os comandos dinamicamente. Quando o Google adiciona um endpoint novo em qualquer API o CLI já suporta automaticamente sem atualização manual.
  
  O que ele cobre: Gmail pra ler, enviar e buscar emails. Drive pra listar, criar e mover arquivos. Calendar pra criar eventos e buscar agenda. Sheets pra ler e escrever em planilhas. Docs pra criar e editar documentos. Slides pra criar apresentações. Chat pra enviar mensagens. Admin pra gerenciar usuários. Tudo com output em JSON estruturado perfeito pra agentes de IA parsearem. Vem com mais de 100 Agent Skills em markdown e 50 receitas prontas pra tarefas comuns.
  
  Até agora pra conectar um agente de IA ao Google Workspace você precisava de Zapier, Make, n8n ou configurar MCP servers manualmente. Cada serviço uma integração separada. Agora o Google tá dizendo: toma, um único ponto de entrada, pode mandar seus agentes. E tem suporte a MCP também, funciona como MCP server pra ferramentas como Antigravity, Claude Desktop e outros clientes MCP. Escrito em Rust, distribuído via npm. Leve, rápido, sem dependências pesadas.
  
  Mostro a instalação ao vivo com npm install -g @googleworkspace/cli, o fluxo de autenticação OAuth e os primeiros comandos funcionando.
  
  Na primeira demo controlo o Gmail direto do terminal. Listar emails não lidos, ler email específico, buscar por assunto e enviar email. Na segunda demo controlo o Google Drive. Listar arquivos recentes, buscar arquivo específico e criar pasta. Na terceira demo controlo o Google Calendar. Ver próximos eventos e criar evento direto do terminal.
  
  Na quarta demo conecto o GWS CLI com o Antigravity como MCP server. Configuro nas settings e pronto, o Antigravity tem acesso ao meu Google Workspace inteiro. Peço em linguagem natural pra resumir meus últimos emails não lidos, verificar horários livres na agenda e criar um Google Doc a partir de emails sobre um projeto. Automação de produtividade em outro nível.
  
  Mostro também as Agent Skills que vêm com o repositório. Mais de 100 skills incluídas: triagem automática de inbox, backup de documentos, criação de relatórios a partir de Sheets, envio de resumos semanais por email, agendamento inteligente de reuniões. E tem proteção contra prompt injection com integração ao Google Model Armor.
  
  Projeto experimental, não é oficialmente suportado pelo Google. Ainda em desenvolvimento ativo. Precisa de um Google Cloud Project pra gerar credenciais OAuth. E dá acesso real aos seus dados então cuidado com o que você autoriza um agente a fazer. O repositório já tem mais de 10 mil stars no GitHub na primeira semana.
