Olha só, se tu tá utilizando o Cloud Code, tu acha que tá pagando muito caro por ele, tu precisa conhecer essa estratégia. Chega aí, o nome dela é Deep Cloud. Em vez de tu rodar os modelos da Tropic, o Opus, o Sonic, tu vai utilizar o Deep Seek. Ele é um modelo top de linha também, só que gasta uma fração do que o Cloud Opus gasta e tu vai ter uma qualidade muito parecida. É bem simples fazer isso. Tu vai utilizar um arquivo

chamado Setting Jon, que é um arquivo padrão de configuração do cloud. Lá tu vai configurar os modelos do Deepsic. Depois tu vai configurar a chave do teuepic, a chave de API no DNEV. E por fim tu vai usar o cloud com os modelos do Deepsic. E aí é só programar normal, pedir os prompts para ele que tu vai ter os mesmos resultados, só que com um modelo muito, muito mais barato.
