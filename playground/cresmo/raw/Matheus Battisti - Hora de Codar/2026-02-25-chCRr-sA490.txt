  Nesse vídeo eu te mostro o que é o Remote Control, como configurar do zero e como usar na prática com cenários reais.
  
  Primeiro explico a diferença crucial entre Remote Control e Claude Code na Web. O Claude Code na Web roda na infraestrutura cloud da Anthropic, é pra quando você tá num hotel sem nada instalado. O Remote Control roda na SUA máquina. Seus arquivos, seus servidores MCP, suas configurações do projeto, tudo continua local. O celular é apenas uma janela pra essa sessão. Como um controle remoto da TV: a TV faz o trabalho pesado, o controle só manda os comandos.
  
  Mostro os dois métodos de ativação. O primeiro é pelo terminal com claude rc, que cria uma sessão nova e gera um QR Code pra conectar pelo celular. O segundo é de dentro de uma sessão que já tá rodando com o comando /rc, que leva todo o histórico da conversa junto. Cada mensagem, cada edição de arquivo, cada chamada de ferramenta. Você não perde nada.
  
  Na demonstração prática faço um cenário real: começo uma refatoração pesada no terminal, ativo o Remote Control, escaneio o QR Code no celular e continuo monitorando e dando instruções pelo app. Mostro a sincronização em tempo real entre os dispositivos e como a reconexão automática funciona se o laptop dormir ou a internet cair.
  
  Explico também como ativar o Remote Control automaticamente em todas as sessões pelo /config, sem precisar digitar /rc toda vez. E mostro o truque com tmux pra criar sessões persistentes que sobrevivem se você fechar o terminal acidentalmente.
  
  Na parte de segurança, o computador só faz conexões HTTPS de saída. Nenhuma porta é aberta. Tudo passa por TLS com credenciais temporárias. Mesmo nível de segurança de uma sessão normal do Claude Code. Pra projetos sensíveis, tem a flag --sandbox que ativa isolamento de filesystem e rede.
  
  Comparo com a concorrência: Cursor tem app iOS mas manda tudo pra cloud. GitHub Copilot tem agente pelo Mobile mas roda via Actions no cloud. O Remote Control do Claude Code é o ÚNICO que mantém execução local com acesso remoto completo. Esse é o diferencial.
  
  Fecho com as limitações que você precisa saber: uma sessão remota por vez, terminal precisa ficar aberto, planos Team e Enterprise ainda não suportados, e o bug conhecido do erro "Contact your administrator" que a Anthropic já reconheceu. E minhas dicas práticas: usar tmux, dar instruções detalhadas antes de sair da mesa, trabalhar em branches separadas, e manter o celular carregado porque a conexão streaming consome bateria.
  
  Requisitos: plano Max ou Pro da Anthropic, Claude Code versão 2.1.52 ou superior.
