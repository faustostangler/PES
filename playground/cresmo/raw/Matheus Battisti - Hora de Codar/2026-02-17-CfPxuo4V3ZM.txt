  Criei o TripAI, um planejador de viagens com inteligência artificial que tem login de usuário, banco de dados, integração com OpenAI e todas as funcionalidades de um app profissional. Tudo isso em aproximadamente 30 minutos.
  
  O processo que eu uso combina 3 ferramentas poderosas. Primeiro o Google Stitch para criar o design e interface do app. Depois o Claude para gerar prompts otimizados. E por fim o Google Antigravity para desenvolver o app completo de forma automática.
  
  O TripAI permite que o usuário faça login, preencha um formulário com destino, número de dias e orçamento, e a IA gera um roteiro completo dia a dia com sugestões para manhã, tarde e noite. O usuário pode salvar suas viagens, visualizar o histórico e deletar roteiros antigos.
  
  A stack do projeto inclui React no frontend, Node.js no backend, SQLite como banco de dados e a API da OpenAI para geração dos roteiros. Tudo isso foi criado pelo Antigravity seguindo as instruções do prompt e os prints do design.
