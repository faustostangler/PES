  Crio um e-commerce completo com Next.js 15, Prisma, NextAuth e shadcn usando cada framework e comparo resultado, tempo, tokens e qualidade.
   
  Se você usa Claude Code e tá na dúvida entre Superpowers e GSD, esse vídeo é pra você. Os 2 frameworks prometem deixar o Claude Code mais profissional, mas atacam problemas diferentes. Superpowers, criado por Jesse Vincent, é um framework de skills baseado em disciplina de desenvolvimento: TDD obrigatório, testes antes do código, review entre tarefas e fluxo estruturado de brainstorming até merge. GSD, criado por Lex Christopherson, é um sistema de context engineering que resolve o problema de context rot mantendo cada tarefa em context fresco com specs externalizadas.
   
  No vídeo eu explico o que cada framework faz. Superpowers ensina o Claude a codar com disciplina: brainstorming antes de código, worktree isolado, plano detalhado, subagents com TDD rigoroso e review entre tarefas. GSD externaliza specs em .planning/ e spawna subagents com context limpo de 200k tokens, organizando tarefas em waves paralelas.
   
  Mostro a instalação dos dois. Superpowers instala como plugin oficial do Claude Code via marketplace. GSD instala via script bash clonando o repositório e rodando install.sh.
   
  Parto pro teste real com o mesmo prompt pros 2 frameworks. Um e-commerce funcional com home, página de produto, carrinho drawer, checkout, confirmação, auth com NextAuth, painel admin, filtro por categoria, busca, responsivo mobile first, dark mode e 12 produtos seed. Pastas separadas, sessão nova pra cada round.
   
  No round do Superpowers você acompanha o fluxo completo: brainstorming ativa sozinho e o Claude faz perguntas antes de codar, cria git worktree isolado, gera plano com tarefas pequenas, spawna subagents que escrevem teste primeiro (RED), implementam (GREEN), refatoram e passam por review entre tarefas.
   
  No round do GSD você vê o fluxo diferente: /gsd:discuss-phase entrevista sobre preferências, plan phase cria specs externalizadas em .planning/ em waves, execute phase roda subagents frescos com commits atômicos, e /gsd:verify-work roda UAT e security audit antes do /gsd:ship.
   
  No scoreboard final comparo tempo, tokens, se funcionou de primeira, qualidade do código, UI, auth, carrinho, checkout, admin, dark mode e responsivo. Dou veredito honesto sobre quando usar Superpowers e quando usar GSD, e qual eu adotei depois desse teste.
