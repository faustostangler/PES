Atestado criptográfico. O problema que os fabricantes de sistemas operacionais tentaram resolver é como garantir que a sede receba informações precisas e certificadas sobre uma máquina, sem a possibilidade de falsificação. Por exemplo, se um sistema operacional quiser descobrir o modelo da máquina em que está sendo executado , ele geralmente lê algum arquivo na máquina e transmite essa informação para a sede como se fossem dados verdadeiros. Mas, como todos sabem, especialmente no Linux, é trivial alterar os valores nesses arquivos ou, no caso do Windows, alterar os valores em um banco de dados de armazenamento chamado registro. Como qualquer pessoa pode escrever no local de armazenamento, nunca há garantia de que seja autêntico ou original. Assim, a Microsoft

concentrou-se numa nova solução que utiliza um chip de segurança instalado de fábrica, chamado TPM. Este pequeno chip possui uma chave pública e uma chave privada exclusivas que podem ser usadas para criptografia e, como é baseado em hardware, não pode ser adulterado . A chave privada não é visível fora do chip e todo esse par de chaves pública e privada é chamado de chave de endosso. A chave pública fica exposta, permitindo que qualquer pessoa consulte o chip e obtenha a chave de aprovação pública. Chaves públicas podem ser usadas para criptografar. Mas

a regra é que apenas a parte que possui a chave privada pode descriptografar. Portanto, se você enviar uma mensagem criptografada para o chip, ele só poderá reproduzir o que você enviou se possuir a chave privada. Normalmente, isso é usado para criptografar um valor secreto utilizando uma chave pública do TPM. Isso se chama selagem. Então, quando você quiser recuperar o valor, basta enviá-lo de volta ao TPM para descriptografá-lo e o conteúdo original poderá ser visualizado. Este é o processo de deslacração.

Como a criptografia foi realizada pelo sistema operacional, o conteúdo dos dados originais pode ser validado pelo sistema operacional a partir dos resultados da descriptografia. Isso garante que o conteúdo foi de fato validado pelo chip TPM e que não foi falsificado. Este encapsulamento criptográfico agora está integrado ao Microsoft Windows 11. Para que esse esquema funcione, observe que é o sistema operacional que realiza o processo de selagem e deslacração, e não o usuário final. Portanto, você realmente não tem controle sobre o que está armazenado em seu dispositivo. A

A implementação completa do TPM consiste no fato de que, durante a inicialização, o carregador de inicialização interage com o TPM e armazena valores sobre si mesmo nos registros de configuração da plataforma do TPM, ou PCR. Os dados que ele observa são as configurações do BIOS ou do firmware UEFI, o carregador de inicialização e o estado da inicialização segura. Embora isso possa parecer apenas jargão técnico para quem não entende de tecnologia, o importante é que esses valores conseguem indicar qual sistema operacional você está usando e qual versão do sistema operacional está ativa. Dessa forma, o TPM sabe se você está executando Linux ou alguma versão mais antiga do Windows em vez do Windows 11. O TPM também é usado para garantir que outras chaves não sejam adulteradas usando o mesmo método criptográfico de criptografia com a chave pública do TPM. Até mesmo

a criptografia do BitLocker é selada na mesma camada de criptografia. Assim, o TPM torna o sistema operacional teoricamente inviolável, exceto para a Microsoft. TPM é uma ferramenta da Microsoft.
