Olá, eu sou Matthias. Bem-vindos ao Novidades no DevTools. Este episódio aborda as versões 145 a 147 do Chrome. Vamos conferir recursos de desempenho para apps de página única, depuração de estilos aprimorada para componentes da web e novos recursos do servidor MCP do Chrome DevTools. Na web moderna, a navegação nem sempre é um recarregamento completo a cada clique.

Os apps de página única apenas atualizam o que precisa mudar, mantendo o usuário no fluxo. Navegações assim parecem contínuas para os usuários, mas sempre foram difíceis de rastrear em análises de desempenho, até agora. Vamos começar. NOVIDADES NO DEVTOOLS Ao registrar o desempenho em um app de página única, você vai ver marcadores dedicados para essas navegações suaves e tempos relacionados. Vamos ter uma linha do tempo clara de quando uma navegação iniciada pelo usuário começa no app de página única, facilitando a otimização para transições realmente perfeitas.

Nos casos em que você precisa analisar os detalhes, os tempos do nosso profiler por linha agora estão muito mais precisos. Corrigimos os problemas com mapas de origem e o código formatado corretamente, assim, mesmo em ambientes de produção minimizados, você pode ver exatamente qual linha de código está causando o gargalo e onde é preciso otimizar. Mas, é claro, o código não é o único gargalo possível. A infraestrutura também pode ser outro fator. Para cobrir melhor casos como esse, adicionamos uma nova coluna "Render Blocking" ao painel "Network".

Ela identifica explicitamente os recursos que estão atrasando seu first paint. Se um script ou uma folha de estilo impedir o usuário de visualizar o conteúdo, isso vai ser sinalizado de imediato. Essas atualizações ajudam a tornar seus sites mais rápidos, sejam gerados por IA ou não. Agora, vamos ver como deixar tudo ainda mais bonito. Depois de desbloquear o first paint, você pode ajustar o estilo dos elementos animados.

O DevTools agora oferece suporte ao estilo @starting por padrão. Essa regra @ permite definir os estilos de um elemento no momento em que ele é renderizado pela primeira vez. É a chave para criar transições de entrada suaves, como fazer um diálogo aparecer com fade direto no CSS, sem JavaScript. Os "@starting-styles" não são os únicos estilos aprimorados na depuração. Agora, as folhas de estilo adotadas aparecem diretamente na árvore DOM, em um nó próprio.

Você pode expandir esse nó e editar as folhas de estilo no painel "Styles", como nas tags de estilo tradicionais. Encerramos as atualizações de CSS com um pequeno ajuste de IU. O Grid Editor tem uma caixa "Dense" para o fluxo automático da grade, o que ajuda você a testar algoritmos de empacotamento sem sair da interface. Clique no botão "Editor" ao lado de qualquer propriedade display grid no seu site. Mesmo com as atualizações no Chrome DevTools, continuamos trazendo o melhor do DevTools para agentes com nosso servidor MCP do Chrome DevTools.

Agora você pode executar auditorias do Lighthouse diretamente pelo MCP. Isso permite que seus agentes verifiquem regressões na acessibilidade, SEO e melhores práticas por meio do agente de programação, usando as mesmas auditorias já conhecidas da interface do DevTools. Para analisar o desempenho, os agentes contam com ferramentas especializadas integradas ao servidor, que permitem registrar e investigar vestígios, além de insights relacionados ao desempenho. Também incluímos diversas funcionalidades ao servidor MCP, como uma habilidade dedicada à depuração de acessibilidade, uma habilidade para medir e depurar LCP e uma habilidade para solucionar problemas na sua instalação do MCP do DevTools. Para citar mais uma das muitas melhorias que fizemos nas últimas semanas, adicionamos um novo modo compacto, que ativa apenas as ferramentas essenciais, reduzindo o custo de tokens iniciais de setup o máximo possível.

Antes de encerrar, uma dica extra, voltando ao CSS: nos painéis "Styles", "Computed" e "Properties", as barras de filtro agora suportam expressões regulares. Se quiser todas as variáveis CSS ou apenas um conjunto de propriedades, use uma RegEx. É uma mudança simples que acelera bastante a navegação em grandes folhas de estilo. Por exemplo, digite ^-- e ative o controle RegEx para filtrar todas as variáveis CSS. Essa foi a edição do Novidades no DevTools para versões 145 a 147.

Desde à avaliação de SPAs até a depuração de agentes, estamos tornando a web mais fácil de construir e depurar.
