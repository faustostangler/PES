Bem-vindos de volta. Hoje, vamos interromper as vibe checks, executar nossos testes e mapear seu conhecimento em testes web para o novo mundo dos LLMs. Imagine um app de exemplo: o ThemeBuilder. Os usuários atribuem um nome de empresa, uma descrição, um público-alvo e um tom, e o sistema chama um LLM para gerar um objeto JSON com um lema e uma paleta de cores que combinem com a marca e o tom. Além disso, as paletas de cores devem ter contraste suficiente para serem acessíveis, e o lema deve ser não tóxico.

Então, como testamos o ThemeBuilder? Para ações objetivas, como JSON válido e taxas de contraste, usamos código normal. Essas são avaliações baseadas em regras. Mas e as questões subjetivas, como adequação à marca ou toxicidade? Conheça o ponto central do seu pipeline: o LLM para atuar como avaliador.

Utilizamos um LLM para simular a revisão humana. Agora, ampliando a perspectiva, os testes de IA têm três objetivos distintos. Primeiro, temos a regressão, como você já conhece: uma alteração no prompt corrompeu acidentalmente seu JSON? Em segundo lugar, a otimização. As avaliações oferecem a comprovação necessária de que seu app está melhorando com o tempo.

E, em terceiro lugar, a seleção do modelo. Os LLMs evoluem rapidamente. Ao contrário do desenvolvimento web padrão, em que você avalia o framework de front-end uma vez e segue com ele, aqui você precisa de avaliações regulares para usar modelos menores, potencialmente mais baratos, sem perder a qualidade. Por isso, os objetivos são diferentes, mas um conceito permanece o mesmo. É um teste de camadas.

Uma base de código íntegra precisa de testes unitários rápidos baseados em regras, testes de unidade ampliados usando LLMs como avaliadores e testes de integração mais abrangentes. Assim, você tem um pipeline de testes de IA totalmente automatizado. Para completar, adicione avaliação humana para um teste final de aceitação. Agora, confira nosso artigo para ter uma visão completa do seu modelo mental para testes de IA e conte o que achou. Em alguns dias, vamos partir para o planejamento e elaborar suas avaliações.
