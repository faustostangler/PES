Olá, meu nome é Matthias. Esta é a sessão Novidades no DevTools para o Chrome 148, 149 e 150. Esses três marcos trazem uma série de novos recursos para o DevTools e para o DevTools para agentes, incluindo ferramentas para depuração de WebMCP, uma experiência nova e mais refinada no painel de assistência por IA e várias melhorias de usabilidade. Mas, primeiro, temos algo a comemorar. O Chrome DevTools para agentes alcançou oficialmente sua primeira versão estável: a versão 1.0.

Vamos descobrir como isso tudo aprimora seu trabalho de programação com agentes. NOVIDADES NO DEVTOOLS Resumo rápido: o DevTools para agentes permite que o agente acesse seu site no navegador ativo, criando um ciclo de feedback fechado para o agente. Dessa forma, ele não precisa mais adivinhar o efeito das alterações. Na versão 1.0, seus agentes podem gerar auditorias completas do Lighthouse diretamente no fluxo de trabalho para detectar e corrigir regressões em acessibilidade, SEO ou boas práticas.

Para mais desempenho, os agentes podem continuar usando ferramentas de rastreamento mais especializadas. O DevTools para agentes também é compatível com a navegação agêntica do Lighthouse, verificando ferramentas WebMCP, checando a acessibilidade para agentes e um possível arquivo LLM.TXT. Com o DevTools para agentes, seu agente de programação agora também pode depurar usando extensões. Isso significa que ele pode inspecionar páginas específicas da extensão e scripts em tempo de execução, o que ajuda a corrigir arquiteturas de extensão complexas.

E, por fim, páginas e frameworks podem expor ferramentas JavaScript personalizadas em tempo de execução. Essas ferramentas vão ser detectadas pelo DevTools para agentes, permitindo depurar comportamentos complexos da página de modo mais preciso e direto. Saiba mais sobre os novos recursos do DevTools para agentes nas notas da versão. Mas, antes de depurar com seu agente, você precisa construir algo. Para isso, a equipe do Chrome lançou o Modern Web Guidance.

O Modern Web Guidance oferece habilidades validadas por especialistas que ajudam seu agente de programação a criar e descobrir os recursos mais recentes da plataforma web alinhados à referência. Veja as instruções de instalação do seu agente de programação e mais informações neste link. Agora vamos abrir o DevTools para ver o painel de assistência de IA atualizado. Com tecnologia do Gemini 3, ele entrega respostas mais concisas e acionáveis e consegue lidar com objetivos complexos de depuração com um único prompt. Em vez de Markdown em texto simples, o novo tutorial do agente renderiza widgets especializados diretamente no chat.

Esses recursos incluem Core Web Vitals, análises de LCP e muito mais. Um clique em "Reveal" leva você diretamente à fonte de dados bruta dentro do DevTools. A assistência de IA também foi aprimorada com acesso direto ao Lighthouse. Ela pode fazer uma análise completa da sua página, por exemplo, para melhorar a acessibilidade ou o desempenho, e oferecer recomendações direcionadas com base em insights reais. Depois da investigação, você pode transferir os resultados para sua base de código local usando o novo botão "Copy to coding agent".

Você pode pegar a conversa completa ou um resumo em formato de prompt para agentes. Vamos conferir algumas atualizações poderosas de produtividade. Começando com cargas especulativas, o painel "Application" agora permite filtrar regras de especulação por texto livre ou chaves como URL e status. No painel "Network", você pode adicionar uma coluna opcional de número da solicitação. Assim, você registra a ordem cronológica absoluta em que as solicitações foram iniciadas e pode usar o recurso de ordenação.

A seguir, o APCA Contrast Calculator foi oficialmente promovido da fase experimental. Ele substitui as diretrizes AAA/AA legadas por um modelo de contraste perceptual otimizado para telas modernas. Defina como padrão em "Settings", "Preferences", "Elements" e ative "Enable APCA contrast guidelines". Por fim, e relacionado a isso, o toggle da árvore de acessibilidade foi movido de um botão flutuante para um toggle dedicado na barra lateral da guia "Accessibility" no painel "Elements". Para terminar, vamos ver as ferramentas de depuração do WebMCP.

O WebMCP é um padrão web proposto que permite aos sites expor ferramentas especializadas diretamente para agentes de IA visitantes. Agora você pode depurar essas ferramentas no painel "Application". Na nova seção "WebMCP", você pode listar ferramentas definidas, acompanhar invocações em tempo real do agente e executar ferramentas manualmente para verificar a saída com segurança. O WebMCP e as ferramentas de depuração do DevTools ainda são experimentais. Acesse as Chrome Flags e ative o suporte ao WebMCP no DevTools e a flag de teste do WebMCP para começar a testar.

Antes de encerrar, uma dica bônus de hoje: sugestões de código para CSS. Ao ajustar estilos na guia "Styles", o DevTools agora oferece sugestões inteligentes de código do Gemini, ajudando a lidar com valores de CSS complexos como gradientes e sombras de forma fácil. Acesse as configurações do DevTools e ative as inovações de IA. Essas são as novidades do Chrome DevTools, desde DevTools para agentes até atualizações de sistemas de IA, para melhorar ferramentas do dia a dia, como contraste de cores e depuração de CSS.
