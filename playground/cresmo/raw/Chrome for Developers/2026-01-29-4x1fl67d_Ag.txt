Have you already heard of MCP? It's short for model context protocol, and long story short, it's APIs specifically designed to be used by AI. DevTools now also offers an MCP server, which can help you debug common issues around web development, using a real Chrome instance on your own device. DevTools MCP works with every IDE that supports the MCP protocol, independently from the used model. Use it with Gemini CLI or ViewScode and Copilot, find Instance instructions and more at Google Slash DevTools MCP.
