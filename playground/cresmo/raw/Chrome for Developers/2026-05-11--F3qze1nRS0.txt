Now, one thing to repeat here deprecation is not removal. You'll sometimes hear developers describe a feature as deprecated, as a shorthand for deprecated and removed. Deprecation is the announcement phase before feature removal. When browser vendors warn developers that they planned to remove a feature. This feature is deprecated.

Well, that means that the feature is still available, but it's scheduled for removal. And typically a feature is disabled and the code for it eventually removed. Several browser versions after deprecation is announced.
