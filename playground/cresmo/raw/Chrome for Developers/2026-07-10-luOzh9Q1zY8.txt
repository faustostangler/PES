Hi, I'm Rory, I'm a Google Developer expert in web technologies from the Netherlands, and today I'm at Google I/O Connect in Berlin and having a great time. Computers were never a big part in my life until I got dial up internet in 1996 with a hit on View Source. I got access to the source code of websites, using the DevTools to find my way around and start making my own websites, and it was great. One of the new things I really like is the modern web guidance. It gives your AI agents and assistants the opportunity to use modern HTML and CSS features while creating code for you.

You don't need as much JavaScript anymore, for instance, that you needed 10 years ago. For all the coders out there, they're going to produce better code as well. You should check it out as well. It's awesome.
