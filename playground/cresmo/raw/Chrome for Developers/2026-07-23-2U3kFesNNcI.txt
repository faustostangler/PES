— Exato. A primeira tarefa do Chrome é descobrir como chegar aos servidores que guardam os recursos da página da web. Imagine que você clicou no link cats.example/tabby. Onde o navegador consegue os recursos dessa página?

Esse processo usa um conjunto de regras de comunicação conhecido como TCP/IP. Essas regras são conhecidas como protocolos. — Um protocolo é um conjunto padronizado de regras para comunicação. Neste exemplo, o Chrome envia uma mensagem para o site, cats.example, seguindo as regras do TCP/IP.

O site responde, então o Chrome responde a essa resposta, até que todo o processo de handshake termine. Uma solicitação de um navegador para um servidor da web é só uma mensagem de texto que segue as regras do protocolo HTTP.

A solicitação HTTP é enviada por meio de uma conexão TCP. Quando ela é feita, o servidor responde com um arquivo. Isso pode ser um arquivo HTML, um arquivo CSS, uma imagem ou qualquer outra coisa. A solicitação e a resposta podem incluir mais informações em formatos de texto. São os chamados cabeçalhos.
