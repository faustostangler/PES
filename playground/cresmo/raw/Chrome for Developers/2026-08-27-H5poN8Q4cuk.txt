We built Chrome DevTools for agents on top of the Chrome DevTools Protocol. This is the underlying protocol used by Chrome DevTools and tools like Puppeteer to control the browser.

Last year, after exposing new extension-related capabilities in the Chrome DevTools Protocol, we were able to launch new features in Puppeteer to make it easier to install extensions in automated tests.
