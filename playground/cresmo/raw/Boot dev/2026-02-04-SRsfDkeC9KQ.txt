Um dos maiores erros que os novos analistas de dados cometem é não entender que os tipos de dados impactam praticamente tudo o que fazem no Power BI. Pode parecer algo realmente pequeno, mas à medida que você começa a desenvolver seus projetos e a criar painéis e todas essas visualizações, se você não fizer isso no início do projeto e não definir corretamente os tipos de dados, isso pode custar muito tempo mais tarde. Cada coluna no Power BI possui um tipo de dados, que simplesmente indica ao Power BI como os valores nessa coluna devem ser tratados. Alguns dos tipos de dados mais comuns com os quais você trabalhará são texto, números inteiros, decimais, datas e valores booleanos. Os tipos de dados afetam bastante as visualizações. Portanto, se

você tiver algo armazenado como texto, não poderá enviar. Você não pode agregar tudo e depois ver, tipo, "ei, quanto tudo isso representa ?". Portanto, não é possível fazer isso com texto. E se você tiver valores de data armazenados como texto, não poderá usá-los para análise de séries temporais. Esses tipos de dados precisam

ser armazenados da maneira correta. Caso contrário, você não poderá usá-los para muitas visualizações de dados, gráficos e tabelas diferentes no Power BI. Então, como você altera dados no Power BI? Bem, existem duas maneiras principais. O primeiro está no Power Query. Você pode simplesmente

selecionar uma coluna e especificar o tipo de dados desejado durante a etapa de limpeza de dados. Você também pode alterar os tipos de dados diretamente na visualização de modelo ou na visualização de tabela do Power BI. Mas devo dizer que quase sempre faço isso no Power Query, porque o Power Query é uma espécie de processo de ingestão. Portanto, se você fizer isso mais tarde , não precisará fazê-lo novamente. E, principalmente se você começar a criar automações, é melhor fazê-lo nessa etapa, pois isso automatiza as alterações de dados quando você atualiza seus dados. E isso é uma

coisa muito boa a se fazer. Como mencionei anteriormente, isso também pode afetar seus gráficos. Por exemplo, se você estiver criando um gráfico de barras, provavelmente desejará que a categoria seja texto ou uma string , mas os valores, muito provavelmente, serão numéricos ou decimais. O Power BI precisa saber que se trata de uma coluna numérica, mas se estiver armazenada como texto, não poderá ser usada em um gráfico de barras. E, claro, isso vai causar problemas. Se você tentar

criar um gráfico de linhas e tiver uma data armazenada como texto, não poderá criar essa data e colocá-la no eixo x. Vai dar erro e não vai funcionar de jeito nenhum. Valores booleanos são frequentemente usados ​​como filtros, como exibir registros ativos versus inativos . Se estiverem armazenados como texto, o Power BI não os lerá como verdadeiro ou falso, e isso pode afetar o filtro. Como você pode ver, os tipos de dados são realmente importantes e é fundamental acertá-los desde o início.
