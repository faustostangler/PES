Que tipo de registro DNS é esse? [música] Muito bem, que tal esta? A diferença é que o primeiro é um registro A, que sempre aponta para um endereço IP, e o segundo é um registro CNAME, que sempre aponta para algum outro nome de domínio. Então, se ambos se resumem a endereços IP em algum momento, por que nos preocuparíamos com um CNAME? O primeiro motivo é permitir a utilização de múltiplos nomes para um servidor. Você poderia ter três endereços

que apontam para o endereço IP de um único servidor usando registros A, e ficaria assim . Mas, se esse endereço IP mudar, o que às vezes acontece com frequência, você precisará atualizar todos os três registros. Em vez disso, você pode usar um único registro A para o servidor e apontar os outros domínios para ele com um registro CNAME, assim. Então, quando o endereço IP mudar, tudo o que você precisa fazer é atualizar o registro A único . O segundo motivo é uma forma de pseudônimo. Se seus usuários

digitam URLs incorretamente com frequência, você pode usar um registro CNAME para direcioná-los para a URL correta. Você pode até usar curingas para capturar subdomínios inteiros. É importante ressaltar que um registro CNAME não é o mesmo que um redirecionamento HTTP. Isso é tratado no nível do DNS antes de qualquer solicitação HTTP ser feita. Isso significa que é muito mais rápido e eficiente, mas também significa que funciona apenas para nomes de domínio, não para URLs ou caminhos. E uma pequena

restrição técnica a lembrar: geralmente não é possível ter um registro CNAME para a raiz do domínio. Isso ocorre porque os registros CNAME não podem coexistir com outros tipos de registro que você normalmente terá na raiz.
