A característica que quero abordar é se __name__ __ é igual a __main__. Essa é uma convenção comum em Python e muitos iniciantes não fazem ideia de como funciona, então quero explicá-la para vocês. Então veja aqui, temos um arquivo helpers.py e neste arquivo queremos chamar esta função create. Em seguida, temos este arquivo main.py. E este arquivo main.py

simplesmente importa este arquivo de auxiliares. Então, se eu executar o arquivo `python helpers.py`, é claro que ele exibirá uma mensagem de boas-vindas do meu módulo. Mas observe o que acontece quando eu executo o arquivo main.py. Também diz "olá" do meu módulo.

O motivo disso é que, sempre que importamos código Python, executamos todo o script que está dentro do módulo importado. Portanto, se importarmos os helpers, qualquer coisa que esteja dentro deste arquivo, nós a executaremos. É assim que a importação funciona, mesmo que você esteja importando apenas um recurso específico. Então, se eu adicionar essa convenção e começarmos por não imprimir o nome, o que você verá agora ao executar ` python main.py` é que ele não imprimirá mais "hello" do meu módulo. O

motivo disso é que essa verificação permite saber se o script Python está sendo executado diretamente. Essa condição só será verdadeira se executarmos esse módulo Python diretamente. Agora, deixe-me mostrar por que isso acontece, porque se eu imprimir o nome aqui, você verá que quando eu executar o main.py, verá que o nome é igual a helpers, e isso ocorre porque esse é o módulo em que estamos. Por outro lado, se eu executar o arquivo helpers.py,

você verá que o nome é igual a main. Portanto, sempre que você executar um script diretamente, a variável `name` nesse script será igual a `__main__`. Mas quando é importado de outra fonte, será igual ao nome do módulo ou, neste caso, do arquivo em questão. Essa verificação simplesmente nos diz se estamos executando esse código diretamente. Se não for esse o caso, então não faça isso. E a

razão para isso é que muitas vezes queremos importar e reutilizar código Python, mas talvez não queiramos que algo aconteça dentro desse script.
