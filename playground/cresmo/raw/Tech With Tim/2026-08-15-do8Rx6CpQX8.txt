So now you know what an agent is, the question is how do you actually build? There's a lot of ways to do this. So what I want to do is map it out for you and there's kind of four tiers that I've come up with based on how much of that agent you're going to be building yourself. Now at the top, you've got no code platforms. This is where you can build an agent by filling out forums or kind of dragging blocks around. No programming, you don't need to be technical. Now below that, you have what I consider low code tools. That's where you can write parts of the agent you're using like a visual canvas, etc. Then you have agent harnesses. This is where you can install a complete, powerful agent and customize it. And then fully at the bottom here, we have full code, where you're effectively just writing the entire thing in a programming language like Python.
