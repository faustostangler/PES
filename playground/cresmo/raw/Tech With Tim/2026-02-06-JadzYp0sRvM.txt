Cordas F. Agora, as strings F permitem incorporar expressões Python diretamente dentro de uma string, facilitando muito a impressão de conteúdo dinâmico. Você pode ver que eu simplesmente coloquei um F antes de uma determinada sequência de caracteres. Pode ser uma string de várias linhas, o que significa que você pode ter três aspas, ou pode usar apenas aspas duplas ou simples padrão. Agora, quando você coloca esse F, seja ele minúsculo ou maiúsculo, não importa, ele permite que você escreva qualquer expressão Python válida dentro de um conjunto de chaves. Então, posso

escrever algo como o nome ou a idade, e isso pegará o valor dessa expressão, que neste caso é apenas uma variável, e o incorporará dentro da string. Na verdade, ele converterá automaticamente qualquer coisa que ainda não seja uma string em uma string para você. Então, neste caso, temos algum int. Normalmente, se tentássemos adicionar esse número inteiro a uma string, receberíamos um erro, mas a string F é inteligente o suficiente para convertê-lo automaticamente em uma string. Então, vou mostrar para vocês que isso funciona apenas para nossa sanidade mental, e vocês podem ver que imprimimos isso e tudo está correto. Agora, se removermos

o F, na verdade não obteremos nada disso . Então, se eu executar meu terminal aqui e fizermos isso novamente, você verá que as chaves aparecem porque não estão sendo interpretadas como parte de uma variável ou expressão.
