Por favor, não escreva código dessa forma. O primeiro erro que vejo repetidamente tem a ver com condições e instruções "se". Então, eu dei um exemplo simples aqui. Como você pode ver, estamos verificando se o usuário está autenticado, se ele é um administrador ou gerente, ou se é um editor com permissão para editar, se o status da conta está ativo, se houve um último login, se a idade dele está entre 18 e 35 anos e se o endereço IP não está nesse intervalo. Existe uma maneira significativamente melhor de escrever isso.

Então, vamos para a versão corrigida e agora vejamos isto. Um código mais longo e mais fácil de entender é sempre melhor do que um código mais curto e complexo. Então, se olharmos para o topo aqui, podemos ver que o que fizemos foi associar cada condição a uma variável. Algumas delas são um pouco redundantes, como " autenticado", por exemplo. Provavelmente não precisamos de uma variável para isso.

Mas, para os outros, isso apenas deixa muito mais claro o que estamos realmente verificando. Então, estamos verificando se eles estão ativos. O último login deles foi válido? Eles têm idade legal? Existe algum endereço IP válido? E

isso está fazendo duas coisas. É como se o código estivesse sendo comentado automaticamente para nós, porque estamos escrevendo como escreveríamos em inglês normal, e estamos simplificando algumas das condições mais longas em uma única variável. Então, descemos aqui e você pode ver que temos todos esses "e", nós os combinamos e agora podemos retornar verdadeiro. Então, se eu quiser ver o que estamos verificando na instrução if, posso ler isso como se fosse inglês. Eles são autenticados? Eles desempenham um

papel adequado? Eles estão ativos? Eles têm um último login registrado? Etc. Bem, o que mostrei aqui foi um pouco exagerado . Estou apenas tentando demonstrar o

ponto. Muitas vezes você terá várias condições diferentes e, em vez de verificá-las todas na instrução if, você pode criar variáveis ​​para simplificar a condição e, em seguida, combinar essas variáveis ​​para que seu código fique legível como inglês, que é realmente o que buscamos.
