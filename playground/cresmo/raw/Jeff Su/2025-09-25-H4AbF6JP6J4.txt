Here's how I map my iPhone's action button to instantly launch chatbt. Doing this eliminates decision fatigue. So now I use AI for tasks I would have skipped before. The setup is simple. We go to settings and search for the action button. Then scroll all the way to

shortcuts. Search for Chajipt. But instead of starting a new chat, choose start dictation. This way I can talk to Chajb when I'm out and about. Plus I can edit before sending. Pro tip. Since I

still want quick access to do not disturb, I've mapped that action to a backtap instead. So, this takes a bit more effort. You have to first create a shortcut to toggle do not disturb. Feel free to take a screenshot and copy the setup. Then, search for backtap. Set

double tap to the shortcut we just created. Toggle do not disturb. And that's it.
