Vamos começar pelo básico. O que é o

Código Claude? Claude Code é a ferramenta de programação de IA em linha de comando da Anthropic. Você o executa no seu terminal, ele lê seus arquivos, entende todo o seu projeto e pode escrever código, corrigir erros, executar testes e fazer commits sem que você precise copiar e colar em uma janela de bate-papo. É um agente que de fato interage com o seu código. Você pode obtê-lo através da CLI do Claude Code , do aplicativo para desktop, da extensão do VS Code ou diretamente pela API.

Funciona com qualquer linguagem, qualquer framework. Então, o que é o Agent OS? O Agent OS é um sistema de código aberto desenvolvido por Brian Kessler na Builder Methods. Ele se integra ao Claude Code e a outras ferramentas de programação com IA para resolver um problema específico. Sua IA não sabe como você constrói as coisas.

Não conhece seus padrões, suas convenções, a missão do seu produto, nem como você estrutura seus arquivos. Então, ele faz suposições e, às vezes, erra. O sistema operacional do agente corrige isso. Ele fornece à sua IA um conjunto documentado de padrões extraídos da sua base de código real e injeta automaticamente os padrões corretos com base no que você está trabalhando. Você para de se explicar repetidamente. A IA começa a

construir da mesma forma que você constrói. As quatro funções principais do Agent OS são: descobrir padrões. Ele extrai padrões e convenções da sua base de código e os transforma em regras documentadas. Implementar padrões. Ele insere os padrões relevantes no seu contexto com base no que você está construindo.

Especificação de forma. Isso ajuda você a criar melhores planos antes de construir. E padrões de índice. Isso mantém tudo organizado, garantindo que o padrão correto esteja disponível no momento certo. Combine o Claude Code com o Agent OS e você terá uma IA que programa rápido e do seu jeito. Essa é a

base de referência. Mas a Anthropic acaba de lançar algo que leva isso a um nível completamente diferente. Claude Opus 4.8 foi lançado em 28 de maio de 2026 e trouxe consigo algo chamado fluxos de trabalho dinâmicos, o que torna os enxames de agentes reais. O Opus 4.8 é um

modelo melhor que o 4.7 em todos os aspectos. A codificação agentiva subiu de 64,3% para 69,2%. Obteve uma pontuação de 84% no teste online Mind 2 Web, o agente de navegador para uso em computadores, ficando à frente tanto do Opus 4.7 quanto do GPT-5.5.

Também corrige os problemas comuns de verbosidade e de chamada de ferramentas da versão 4.7. Mas o principal recurso são os fluxos de trabalho dinâmicos. Eis o que isso significa em palavras simples. O Claude Code agora consegue pegar uma grande tarefa, como uma migração de base de código, uma auditoria de segurança ou uma varredura de bugs, e dividi-la em centenas de partes menores. Em seguida, ele

ativa subagentes paralelos para trabalharem nessas partes simultaneamente. E então, outros agentes atuam como revisores. Eles tentam encontrar falhas no trabalho e verificá-lo antes que qualquer coisa seja devolvida a você. O processo se repete até que as respostas convirjam. Atualmente, o sistema executa até 16 agentes simultâneos e cada fluxo de trabalho pode usar até 1.000 agentes no

total em uma única execução. Jarod Sumner utilizou fluxos de trabalho dinâmicos para portar o ambiente de execução Bun de Zig para Rust. Centenas de agentes trabalhando em paralelo, com dois revisores por arquivo. Agora, deixe-me mostrar como ligar isso. Existe um novo controle de esforço no código Claude. Vai

do nível mais baixo ao mais alto, num total de seis níveis. E no topo da lista está uma nova configuração chamada ultra código. Ultra código não é apenas esforço máximo mais um. Ele combina o mais alto nível de raciocínio prático com a orquestração automática e dinâmica do fluxo de trabalho . Você liga o programa, atribui uma tarefa importante ao Claude, e ele cuida do planejamento, da criação de subagentes e da verificação automaticamente. Você

pode acioná-lo de duas maneiras. Primeiro, digite a palavra "flowwork" (fluxo de trabalho) em qualquer lugar do seu prompt. Por exemplo, execute um fluxo de trabalho para auditar todos os endpoints da API em src/routes/ em busca de verificações de autenticação ausentes. Claude pega a bola e dá o pontapé inicial. Segundo, digite /effort ultracode na sua sessão para ativá-lo . A partir desse ponto, Claude decide por conta

própria quando uma tarefa é grande o suficiente para justificar um fluxo de trabalho completo. Um ponto importante: os fluxos de trabalho dinâmicos utilizam significativamente mais tokens do que uma sessão normal. Portanto, o sistema pede que você confirme antes de iniciar. Trata-se de uma prévia de pesquisa disponível no momento na CLI, no aplicativo para desktop, na extensão do VS Code e na API. Para usuários dos planos Max e Team, os fluxos de trabalho dinâmicos estão ativados por padrão. Para

planos empresariais, eles estão desativados por padrão. Seu administrador pode ativá-los nas configurações do Claude Code. E para tarefas menores, basta usar o código Claude normal. Ultracode é para coisas grandes. Agora, é aqui que tudo se encaixa.

Eis o modelo mental que facilita tudo . Eu chamo isso de pilha de enxame "na medida certa" (ou "na medida certa para o tamanho ideal"). Cinco passos, cinco palavras. Comandar, enxamear, verificar, vigiar, manter. Primeiro passo, comando. Você dá uma instrução simples em linguagem clara

. Essa é toda a sua função. Audite meu projeto. Migre esta base de código. Encontre todos os bugs. Você é o maestro.
