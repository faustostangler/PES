  Build a Free AI Agent Operating System (No Code): The 5-Layer Compound Agent Stack
  
  This episode explains how to build a free, no-code “agent operating system” that puts multiple AI agents and models (e.g., Claude, Hermes, OpenClaude, FreeClaude Code, and free/local models via free APIs) on one dashboard with shared memory so work doesn’t reset each session. It introduces a five-layer “compound agent stack”: (1) a mission-control dashboard built by prompting an AI coding agent, (2) a shared memory layer—recommended as a local Obsidian vault—that every agent reads and logs to, (3) a router that sends each task to the best model for that job based on testing (referencing Goldie Bench), (4) parallel worker agents coordinated via a Kanban board and a commander agent, and (5) loop engineering so wins feed memory and new models slot in without rebuilding, keeping the system future-proof.
