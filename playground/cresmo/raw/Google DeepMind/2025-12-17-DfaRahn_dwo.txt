SPEAKER: Gemini 3 Flash can handle a huge number of function calls reliably at low latency. In this function calling challenge, it must successfully sequence tasks to prepare dishes. Let's cook some ramen. We start with a hundred ingredients and a hundred tools, which the model has to reason across simultaneously. Each kitchen tool is a separate function call.

There are three agents powered by Gemini 3 Flash. The cooking agent triggers the function calls. It plans ahead by combining raw ingredients to use later on. New combinations get added to the ingredients list. Each new combination is being generated live by the alchemy agent with super-low latency.

You can imagine this function calling setup working in any environment with multiple agents and a large number of tools that the model can use. OK, looking at the Kitchen Log, we can see the ramen is starting to come together. And it looks like the verification agent is happy with the final outcome.
