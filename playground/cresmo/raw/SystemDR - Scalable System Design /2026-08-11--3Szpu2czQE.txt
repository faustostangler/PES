Here's the single mental model I want you to leave with, even if you forget everything else. Every AI-generated code artifact should be scored across five largely independent axes. Collapsing them into one accuracy number silently drops four of the five. Axis one, functional correctness. This is the axis [music] benchmarks already measure, but only against a fixed, often small, test set. It does not generalize

to edge cases outside [music] that suite. Axis two, maintainability. Complexity, readability, coupling, [music] and the review cost that compounds over time. A function that passes tests today can still raise your [music] team's average review time next quarter. Axis three, security. Generated code has

been shown to reproduce insecure patterns from its training data. String concatenation, [music] SQL, permissive deserialization, even when a secure idiom was available and just as easy to [music] write. Axis four, efficiency. Language models default to the most commonly seen implementation in their training data, [music] which is frequently not the asymptotically optimal one for your actual input distribution. And axis five, the one everyone [music] forgets, verifiable trust. Can a human
