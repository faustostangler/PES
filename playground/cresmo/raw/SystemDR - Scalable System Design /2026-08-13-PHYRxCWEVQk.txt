Here's the one picture to hold on to for the rest of this lesson. Every document that enters the system moves through four layers, strictly in order, and the key idea is that each [music] layer only trusts what actually survived the layer before it. Intake is the security gatekeeper. Every file [music] gets a format check and a virus scan before anything else happens. Analysis [music] is where the real intelligence work happens. Content gets

chunked, classified, and scanned for PII. Compliance is where privacy [music] rules actually get applied and audit logs get generated. And storage is where the processed document finally [music] lands, encrypted with access controls attached. The detail at the [music] bottom of this slide is the one I want you to really sit with. If intake flags a file as malware, that file does not travel downstream.

>> [music] >> Analysis never sees its content, compliance never logs anything about it, storage never touches it. [music] But the rejection itself still gets recorded. That's the same principle you've seen in earlier lessons. A security [music] event is worth knowing about even when nothing downstream of it ever actually runs. Keep this four-layer pipeline in mind.
