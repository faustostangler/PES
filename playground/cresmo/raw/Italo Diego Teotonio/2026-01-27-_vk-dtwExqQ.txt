  🔧 Resumo rápido — Como configurar o Claude para controlar o Power BI com MCP
  
  1️⃣ Instale o Visual Studio Code e o Claude Desktop
  
  2️⃣ No VS Code, instale a extensão Power BI Modeling MCP
  
  3️⃣ Acesse a pasta de extensões do VS Code (Windows):
  %USERPROFILE%\.vscode\extensions
  
  
  4️⃣ Localize o executável do MCP:
  powerbi_modeling_mcp
  └── Server
      └── powerbi_modeling_mcp.exe
  
  
  5️⃣ Copie o caminho completo do executável e salve em algum local (bloco de notas). Exemplo do caminho abaixo:
  
  C:\Users\SeuUsuario\.vscode\extensions\powerbi_modeling_mcp\Server\powerbi_modeling_mcp.exe
  
  
  6️⃣ Crie o arquivo de configuração do MCP no Claude com o script abaixo:
  {
    "mcpServers": {
      "powerbi-modeling-mcp": {
        "command": COLE_AQUI_O_CAMINHO_DO_EXECUTÁVEL,
        "args": ["--start"],
        "type": "stdio"
      }
    }
  }
  
  
  7️⃣ IMPORTANTE: no JSON, substitua cada \ por \\
  
  8️⃣ Salve o arquivo e reinicie o Claude Desktop
