Um desenvolvedor lançou no GitHub um arquivo HTML com acesso unificado a IA. O projeto se chama God Mode e roda direto no navegador. Ele conecta você a múltiplos modelos como charterpt, cloud e Gemini. Tudo através da API do Openouter, que centraliza dezenas de modelos. A interface é gratuita e não exige instalação ou cadastro prévio.

Basta abrir o arquivo no navegador e começar a usar. O diferencial está no recurso God Mode Classic, que compara respostas simultaneamente. Você envia um prompt e vários modelos respondem ao mesmo tempo. Isso facilita a comparação de qualidade entre diferentes respostas de IA. A interface roda localmente, mas as requisições vão para API. Para usar,

você precisa de uma chave de API do Open Houter. Openouter oferece modelos gratuitos com limite diário e modelos pagos sob demanda. É uma alternativa prática para quem trabalha com múltiplas IAS diariamente.
