A gente é um chatbot, a gente é um aplicativo que usa a API do chat GPT. E a verdade é que o termo agente ainda não tem uma definição fechada. Para uns é um sistema autônomo, para outros é um fluxo de trabalho automatizado. Mas hoje eu quero organizar essa confusão de uma vez por todas. Vamos então começar pelas

Do outro, os agentes, sistemas em que a IA define sozinha os próprios passos e as ferramentas. De uma maneira mais simples, mais sucinta, nós podemos dizer então que um agente é uma IA que toca uma tarefa do início ao fim. Mas

atenção, conversar com o chat EPT, o Gemini ou Clud ainda não é um agente. Um chat comum faz uma coisa só, te entrega uma informação. E existe um detalhe sobre esses chats que quase ninguém sabe. Tudo que você escreve na conversa vira parte do prompt. A maioria acha que o prompt é só a frase que você digita e dá enter, mas não é. A cada interação, o

que você escreve e o que o modelo responde entram no prompt. Isso vai enchendo uma coisa chamada de janela de contexto ou janela contextual. Até o pensamento do modelo, o resuminho do raciocínio entra nessa janela. Ou seja, o sistema nunca olha só pra sua última mensagem, ele olha para toda a conversa do início ao fim. Mas por mais inteligente que essa interação pareça, isso ainda é um chat e não um agente. A

diferença prática está em outra palavra: ferramentas. O agente executa ações. Um exemplo bem concreto. Você pode pedir, reserve para mim amanhã uma mesa às 3 da tarde. Se aí reservar de verdade, isso é um agente. Mas se você disser: "Me

recomende um restaurante" e ela te devolve uma lista, é um chatbot. A diferença entre esses dois exemplos é uma só. ação, o agente faz e o chatbot responde. E parte da confusão acontece porque cada laboratório usa o termo de um jeito diferente. A Openei, por exemplo, tem um modo agente, com definição própria. Por isso, é tão

difícil dizer quando algo é ou não é um agente de verdade. Para entender agentes, primeiro entenda o que está por baixo deles. O modelo de linguagem, o famoso LLM, é o sistema que responde utilizando a linguagem humana. Você quase sempre fala com LLM por uma tela de chat, mas o chat não é o único caminho. Dá para usar o modelo por uma API ou então por um agente de código como o Cloud Code ou Codex, por exemplo.

E quatro conceitos sustentam qualquer modelo de linguagem. O primeiro é o treinamento. Uma quantidade gigantesca de texto da humanidade entra numa rede neural. Essa rede cria estruturas matemáticas para entender a linguagem e daí vem o raciocínio. O segundo é o contexto. É o texto que você fornece

somado as respostas que o próprio modelo vai gerando. O terceiro é a atenção. Para responder, o modelo não usa a rede neural inteira, não caberia na resposta. A atenção seleciona só o pedaço que importa naquela resposta. Se um dia você quiser programar agentes, você precisa entender esse conceito a atenção. O

quarto conceito é a resposta. A resposta surge do contexto da atenção que geram uma resposta e essa resposta, por sua vez, volta pro contexto novamente, gerando novas respostas.
