Enquanto muitos falam sobre o Opus 4.6, poucos perceberam a verdadeira inovação. O Cloud Code lançou um recurso experimental chamado Agent Teams. Essa funcionalidade muda completamente a forma como os agentes trabalham juntos. Nos agentes tradicionais, cada subagente opera de forma isolada e independente.

Eles executam tarefas individuais, mas não se comunicam entre si diretamente. Todos os subagentes apenas reportam de volta ao agente principal. [música] Se há um agente para interface, banco de dados e backend. Esses três trabalham separadamente, sem trocar informações entre eles. Com Agent [música] Teams, a dinâmica é completamente diferente e colaborativa. O sistema cria

automaticamente um líder de equipe para coordenar tudo. Esse líder funciona como um gerente intermediário que organiza o trabalho. Os subagentes agora podem conversar diretamente uns com os outros. Interface pode falar com banco de dados. Backend pode falar com interface. Toda

essa comunicação é coordenada e enviada ao líder da equipe. Isso permite que múltiplos agentes trabalhem simultaneamente em projetos complexos. A principal desvantagem é o maior consumo de tokens comparado aos agentes tradicionais. Esse custo pode valer a pena para quem possui planos avançados.
