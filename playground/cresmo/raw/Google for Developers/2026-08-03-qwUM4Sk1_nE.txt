Vejamos um desafio de resolução de dependência. Lógica pura, não é necessário saber usar linguagens. Três pacotes chegam ao app e todos querem a mesma dependência. O app precisa de UI, API e Auth. Cada um tem uma versão.

Eles são instalados sem problemas. O problema é a dependência compartilhada, o Core. A UI requer o Core na versão 1.0 ou superior, mas inferior a 3.0.

A API requer o Core 2.0 ou superior. E a Auth aceita qualquer Core, exceto a versão 2.0. Existe um bug conhecido nessa versão.

O registro tem o Core 1.0, 2.0 e 3.0. Duas regras para este enigma: só é possível instalar uma versão de cada pacote; e a versão válida mais recente prevalece.
