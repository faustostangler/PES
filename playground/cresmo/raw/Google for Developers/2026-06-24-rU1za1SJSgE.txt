Seu pipeline espera JSON, e seu prompt diz "Retornar apenas JSON válido", mas o modelo responde com "Claro, aqui está o JSON", e seu analisador falha. Às vezes, apenas o prompting não é suficiente para gerar resultados consistentes. É aí que entra a preparação dos seus dados para o ajuste fino. Prompts são ótimos para controle em runtime, mas podem ser frágeis quando o sistema exige saídas consistentes. Em vez de escrever um prompt mais longo para aplicar comportamentos, você pode usar destilação de conjunto de dados: usando um modelo de fronteira maior para gerar um conjunto de dados limpo e ajustar um menor e mais rápido.

Seu conjunto de dados de ajuste fino destilado ensina o modelo a repetir comportamentos, treinando com exemplos limpos e estruturados exatamente como exigido. Para esta entrada, retorne esta estrutura JSON. Use os campos e valores permitidos. Não inclua Markdown, comentários nem nada antes ou depois do objeto. Em vez de escrever um prompt mais longo, você treina o modelo com exemplos em que a resposta correta é apenas a saída estruturada.

Os prompts dizem ao modelo o que você quer agora. O ajuste fino ensina ao modelo um padrão que ele pode repetir. Para quem trabalha com modelos de pesos abertos, essa distinção importa. Conte nos comentários alguns dos seus melhores casos de uso do ajuste fino e faça a inscrição no canal para ver mais dicas técnicas.
