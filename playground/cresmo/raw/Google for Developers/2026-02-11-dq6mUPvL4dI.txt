A nova era do comércio agêntico chegou. Temos um novo padrão de código aberto: Universal Commerce Protocol, ou UCP. O UCP melhora as experiências agênticas no ecossistema comercial ao criar uma linguagem compartilhada para conectar os serviços ao consumidor, as empresas e os provedores de pagamento. De imediato, ele funciona com a estrutura de comércio e varejo atual. O UCP define padrões para APIs existentes, servidores MCP para ferramentas de agente e A2A para agentes completos.

O UCP também suporta AP2, que comprova a autorização humana para transações. O UCP substitui sistemas antigos com uma única camada de abstração segura que simplifica toda a jornada de compra, da descoberta à entrega final e gestão de pedidos. Ele reduz custos de integração para os comerciantes utilizando uma única linguagem universal para comércio. Como resultado, os serviços ao consumidor geram melhor custo-benefício aos compradores. O UCP é um projeto de código aberto, e os desenvolvedores podem participar hoje mesmo no GitHub.

Leia a documentação e os exemplos, participe de discussões ou envie uma solicitação de pull. Confira o blog para saber mais sobre o Universal Commerce Protocol. Ou, se quiser criar um exemplo, acesse o repositório do UCP no GitHub.
