Today, we're going to take a closer look at the New Gemini 3.5 live translation model that's now available via the Gemini API. Let's go. This is using the Gemini API together with life Genkit and Google Cloud Run to deploy an application that can broadcast speech in many, many different languages using Gemini Live translate.

What you can see here is that in our application now, anytime someone requests that certain language, we set up a new live translate session with that requested language. So you can see here rather than setting up another session, we're actually now subscribing that listener to that existing session. We still have one French listener. Then when the last listener goes, we're also closing that WebSocket here. We're actually using Next.js for our application.

And the really cool thing is by deploying Next.js to Google Cloud Run, we can actually have these long running WebSockets. And then it will use WebRTC to broadcast the audio as well, as it will use the WebRTC data channels to broadcast the captions, which is really cool. This demo is open source. So you can find it on the Google Gemini GitHub account.
