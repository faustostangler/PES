Estou aqui no Google I/O, onde o time do Chrome acabou de anunciar novas ferramentas agênticas de desenvolvimento web e recursos para ajudar você a dar vida às suas ideias mais ambiciosas. Tentando acompanhar as novas funcionalidades da web que surgem por aí? O Modern Web Guidance está aqui para ajudar. Esse conjunto abrangente de habilidades, validado por especialistas, oferece aos agentes de IA uma base para desenvolver recursos modernos para a web. O WebMCP permite que você faça seus sites funcionarem perfeitamente com agentes.

Use ferramentas estruturadas, como funções JavaScript ou formulários HTML, com agentes no navegador, oferecendo mais controle sobre como e onde eles interagem com seu site. E se o agente pudesse processar seu código também? Agora, ele pode. Com o Chrome DevTools para agentes, seu agente pode depurar de forma autônoma e testar o desempenho, permitindo que você verifique e otimize o código que ele está escrevendo. É hora de redefinir o que é possível com o desenvolvimento web agêntico.

Estamos ansiosos para ver o que você vai criar com essas novidades incríveis.
