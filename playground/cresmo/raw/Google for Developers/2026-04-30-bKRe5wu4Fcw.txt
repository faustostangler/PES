Hoje, vamos mostrar novidades do Google Cloud Next, o novo Gemma 4 e instruções sobre a transmissão ao vivo do Google I/O deste ano.

GOOGLE DEV NEWS O Google Cloud Next é o maior encontro anual de desenvolvedores Google Cloud. Na semana passada, em Las Vegas, alguns elementos fundamentais para o futuro foram abordados: IA agêntica, infraestrutura moderna e resolução prática de problemas. Houve muitos anúncios incríveis sobre grandes eventos. Imagine planejar uma maratona ao longo de toda uma cidade. É um pesadelo logístico.

Mas, e se uma equipe de agentes de IA pudesse orquestrar tudo isso? O Google Cloud acaba de lançar o Race Condition. É uma simulação de vários agentes, de código totalmente aberto, com tecnologia da nova Plataforma de agentes do Gemini Enterprise. - É uma empreitada gigantesca. Mas, imagino que planejar uma maratona certificada seja ainda mais difícil.

Há órgãos governamentais com padrões essenciais rigorosos, logística urbana, fechamento de vias e instalação de tendas médicas. - Exatamente, e se você errar uma única variável, tudo pode ruir. Devido a essa complexidade, criamos o Race Condition. - Trata-se de uma arquitetura de referência implantável para orquestrar, escalonar e proteger agentes de IA autônomos, usando a Plataforma de agentes do Gemini Enterprise, e tudo com código aberto. É uma simulação de vários agentes que modela uma maratona em Las Vegas, onde será o Google Cloud Next este ano.

Criamos essa solução para desenvolvedores em conjunto com o Race Condition, de modo que você possa conhecer a arquitetura do sistema, as experiências de demonstração e a inspeção do código diretamente. - Para começar a usar o Race Condition no seu próprio projeto do Google Cloud, confira o repositório do GitHub, com link na descrição abaixo. O Next também trouxe novidades para quem trabalha com agentes de IA. Apresentamos uma nova CLI para criar agentes de IA do zero. Agora, é possível ir do início à produção com apenas uma CLI.

- É uma alegria apresentar o Agents CLI. AGENTS CLI NA PLATAFORMA DE AGENTES Trata-se de uma ferramenta única que facilita a criação e a implantação de agentes do ADK, tanto para você quanto para as ferramentas de agentes de codificação, como CLI do Gemini, Antigravity e qualquer outro agente. - Isso mesmo. Pense no Agents CLI como uma ponte. Ele reúne todas as ferramentas do Google Cloud de que você precisa em uma interface de linha de comando simples.

E o melhor: ele vem com um conjunto de habilidades para orientar o agente de codificação ao longo de todo o processo. - Confira o vídeo completo do anúncio. Ou, se quiser começar a usar o Agents CLI, acesse o link na descrição. O Race Condition e o Agents CLI são apenas duas das muitas novidades incríveis apresentadas no Google Cloud Next. Caso queira conferir a lista completa de anúncios, veja o link na descrição.

O Google DeepMind lançou seu mais recente modelo aberto: o Gemma 4. - Hoje, temos o prazer de anunciar o Gemma 4. Criado com a mesma pesquisa e tecnologia de ponta do Gemini 3, o Gemma 4 é uma família de modelos abertos que operam diretamente no hardware que você já tem: smartphones, laptops e computadores. Pela primeira vez, lançamos o Gemma sob a licença de código aberto Apache 2.0.

- O que isso significa para a comunidade de código aberto? O cofundador e CEO do Hugging Face disse o seguinte sobre o Gemma 4: "O lançamento do Gemma 4 sob a licença do Apache 2.0 é um marco muito importante. É um grande prazer apoiar a família do Gemma 4 no Hugging Face desde o primeiro dia." O Gemma 4 opera em hardware como dispositivos Android, GPUs de laptops, estações de trabalho para desenvolvedores e aceleradores em nuvem.

Ele oferece quatro novos tamanhos de modelo: Effective 2B, Effective 4B, 26B Mixture of Experts e 31B Dense. Toda a família vai além do chat simples, gerenciando lógica complexa e fluxos de trabalho com agentes. Os modelos maiores oferecem desempenho incrível para os tamanhos, superando concorrentes 10 vezes maiores. Para saber mais e começar a usar o Gemma 4, veja o blog do anúncio no link abaixo.
