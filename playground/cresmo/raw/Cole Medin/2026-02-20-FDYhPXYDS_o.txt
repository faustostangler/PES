  Claude Code is incredibly powerful, but reviewing changes across multiple files and managing parallel sessions gets messy fast. Kintsugi is a free Agentic Development Environment (ADE) built on top of Claude Code by the team at Sonar (makers of SonarQube). It doesn't replace Claude Code - it gives you a visual layer to orchestrate sessions, review AI-generated code like a PR, and catch quality issues before they ship.
  
  🔗 Try Kintsugi (free): https://fandf.co/4afFFBc
  
  Kintsugi is macOS only and still in its early experimental phase — the team is actively looking for Claude Code users to provide feedback.

Se você já dedicou algum tempo a estudar o Código Claude, sabe que ele é extremamente poderoso. Agora eu o utilizo para todo o meu desenvolvimento. Mas, quanto mais você o usa, mais começa a perceber que ele tem algumas lacunas. E a maior lacuna para mim é revisar toda a saída do Claude Code. Como vocês podem ver aqui, Claude está passando por uma série de mudanças para mim, e isso é maravilhoso. Mas, quando

chega a hora de revisar o resultado da IA ​​no código — e sejamos sinceros, isso ainda é necessário —, torna-se um processo cansativo, especialmente quando tenho várias instâncias do Claude Code rodando em paralelo, o que acontece o tempo todo. Ultimamente, tenho adorado esta ferramenta gratuita chamada Kintsugi. E o melhor de tudo é que não tenta substituir Claude Code. Isso seria um fator decisivo para mim. Em vez disso, é construído sobre a ferramenta. Então, ainda estamos

usando o Claude Code para tudo, mas o Kintsugi é o que chamamos de ambiente de desenvolvimento agente. Portanto, é uma camada visual adicional que nos permite ver todos os nossos agentes do Claude Code em execução em paralelo, observar todas as alterações de código e revisar tudo. E há muitas coisas que eu adoro nessa plataforma. Quer dizer, a coisa mais importante para mim é simplesmente poder ver todas as minhas sessões paralelas em um só lugar. E consigo ver o que precisa da minha revisão, o que ainda está em execução. E então, quando o

agente cria um plano de ataque, eu posso revisá-lo e até mesmo fazer comentários que serão abordados em tempo real. E depois que a implementação é concluída e a revisão é devolvida para mim, eu consigo analisar algo mais parecido com uma solicitação de pull request, em vez de ter que vasculhar todos os logs do Claude Code e examinar todos os arquivos individualmente. Portanto, é uma experiência muito melhor para mim. E algo bastante inovador que está integrado a isso é que podemos aplicar diferentes tipos de revisões de código ao código gerado por IA, inclusive uma revisão de segurança, o que faz sentido, já que foi uma equipe da Sonar que desenvolveu isso, mas eu simplesmente adoro. Agora, a Sonar deixa bem claro que o Kintsugi é exclusivo para macOS e está em fase experimental neste momento. É também por isso que

é gratuito, mas já é tão poderoso, facilitando o gerenciamento do Claude Code, e ainda podemos usar nossos fluxos de trabalho agentivos. Então, quando a Sonar entrou em contato comigo para testar essa ferramenta e compartilhá-la com vocês, eu agarrei a oportunidade. É algo que eu acho genuinamente muito legal. Portanto, agradeço ao Sonar por isso e definitivamente recomendo que experimentem o Kintsugi. Vou colocar um link na descrição.
