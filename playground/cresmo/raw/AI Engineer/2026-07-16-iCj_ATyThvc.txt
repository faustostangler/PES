Ok, obviamente ninguém está tentando escrever código manualmente para burlar um modelo. No entanto, a engenharia de software, como profissão, ainda existe, e muitas pessoas trabalham treinando esses modelos, sendo essa uma das profissões mais bem pagas atualmente. Ao mesmo tempo, isso torna algumas habilidades de nível superior muito mais valiosas. Na verdade, fazer pesquisa automotiva é muito parecido com treinar um modelo. Outra coisa que considero muito subestimada é a abstração baseada em código. A abstração fornece a estrutura sobre a qual a pesquisa automatizada pode iterar e, bem, esse é também o ponto de partida que influencia enormemente toda a direção da busca. Isso se assemelha muito ao projeto de arquitetura em redes neurais. Em teoria, diferentes arquiteturas podem representar a mesma função, mas a arquitetura, sistematicamente, facilita o aprendizado de algumas funções . E uma boa arquitetura direciona a otimização para soluções que generalizam melhor e têm melhor desempenho, mesmo quando a perda no treinamento possa parecer a mesma. O

mesmo se aplica à pesquisa automotiva. Eis um exemplo. Executamos pesquisas automatizadas para um pipeline de detecção de fraudes e estamos tentando otimizar o processamento de preparação de dados. Inicialmente, fornecemos uma API flexível onde a mesma função processa os dados de treinamento e teste, e a pontuação parece ótima, mas a solução foi comprometida porque certas informações do conjunto de teste vazaram para os dados de treinamento. Em seguida, restringimos ainda mais o acesso aos dados, implementando uma API mais rigorosa, na qual os dados de teste não conseguiam alcançar os dados de treinamento, e a taxa de vazamento de dados caiu para zero.

Nesse caso, uma boa abstração leva a melhores soluções. Mesmo que, se o agente realmente quiser, ele possa direcionar o programa de recompensas. Então, o que quero dizer é que usar a pesquisa automática é uma nova arte. Trata-se de projetar um ambiente para que um agente possa progredir, e ainda estamos no início desse processo.
