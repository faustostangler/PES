  ❓ PERGUNTAS FREQUENTES
  
  P: Quando usar ML clássico em vez de ChatGPT para análise de texto?
  R: ML clássico é a escolha certa quando você tem categorias definidas, precisa de escala e custo controlado, precisão auditável, ou estabilidade de resultado. LLM é melhor quando o texto tem nuance, ironia ou ambiguidade que depende de contexto para ser interpretado. A pergunta que guia a decisão: esse texto precisa ser compreendido ou classificado?
  
  P: O que é análise de sentimento com ML e como funciona?
  R: Análise de sentimento com ML classifica texto como positivo, negativo ou neutro usando algoritmos treinados em exemplos rotulados. Diferente de LLMs, o modelo ML aplica regras aprendidas de forma consistente e auditável, mas precisa de definição operacional precisa das categorias para não gerar erros de padrão.
  
  P: O que é naive classifier e por que acurácia alta pode enganar?
  R: Naive classifier é um modelo que aprende a sempre prever a classe mais frequente nos dados de treinamento. Se 90% dos seus dados são de uma categoria, o modelo acerta 90% das vezes sem aprender nada. Por isso acurácia sozinha não é suficiente, você precisa de F1, precision e recall por classe para entender se o modelo realmente está funcionando.
  
  P: Quais ferramentas open source usar para NLP em português?
  R: BERTimbau para análise de sentimento e classificação com contexto em português brasileiro (disponível no Hugging Face). spaCy para NER e processamento em escala. scikit-learn para classificação supervisionada. Gensim com LDA para descoberta de temas sem categorias predefinidas. Todas são open source e gratuitas.
  
  P: O que é overfitting em modelos de NLP?
  R: Overfitting acontece quando o modelo aprende os dados de treinamento tão bem que perde a capacidade de generalizar para dados novos. O modelo 'decora' os exemplos em vez de aprender o padrão. A solução padrão é five-fold cross-validation, avaliar o modelo em cinco subconjuntos diferentes dos dados para garantir que a performance é consistente.
