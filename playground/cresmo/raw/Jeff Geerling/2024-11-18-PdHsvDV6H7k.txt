This is six external HDMI displays running off of one Raspberry Pi 5. How am I doing this? Well, I have an external GPU, the Radeon Pro W7700, and it has four DisplayPort outputs, and I'm using the Pi's two HDMI outputs. So I have screen one, and we'll move it over to screen two, three, four, five, six, and back to one. Can it game?

Of course! I can run 4K Doom Eternal at about 20 FPS, maybe 15 to 20 FPS. I can do ray tracing even, but ray tracing goes down to like 12 to 15 FPS, so not very playable. It works with Bluetooth, so I have my Xbox controller. I can use Steam Link and stream in 4K, but a lot of games actually play directly on the setup.

There's a Raspberry Pi 5. It has a PCIe connection over to Oculink, Oculink to this little GPU dock, and this is an AMD GPU. So now, Nvidia GPUs don't work. Only AMD. Sorry about that.

But another problem is ARM64, which the Raspberry Pi uses. AMD doesn't support that for ROCm, so you can't run LLMs on this yet. But you might be able to at some point if they get Vulkan working. And Nvidia cards don't work at all yet. There's a problem with the driver that nobody seems to be able to help me with.

And someday maybe we'll get Nvidia cards working on here. Somebody's also trying for Intel. But if you want your 6 monitor battle station with the Raspberry Pi 5, it's possible now.
