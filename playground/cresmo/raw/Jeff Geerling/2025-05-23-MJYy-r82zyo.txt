This looks like any old mechanical keyboard, but if you flip it over, underneath there are actually two computers. You can plug the keyboard into any computer with USB, and this little Raspberry Pi microcontroller lets you type like normal. But plug-in power up here, and this Raspberry Pi Compute Module boots up an AI model, and you can talk or type, giving this keyboard its name, the Talk or Type [actually TypeOrTalk]. Now, this is a prototype, in case that wasn't obvious, but the way it works is better than Windows or Apple's built-in dictation features. Why? Because it doesn't record you and send those recordings up to the cloud.

Well, I have to qualify what I mean by "better" though. Better for privacy, sure, but I should give you a live demo. "My voice is my passport."

"Verify me." Oh, and I forgot to mention, because it's just a regular keyboard, you can use it with any computer. That's another advantage. So if you're rocking a vintage Power Mac or a toilet iBook G3, it'll still work. But it is pretty bad at splitting up longer phrases.

That's a software issue, and that can be worked out. The crazy thing is this whole project was put together by one guy, Sam, who's auctioning off his first prototype, presumably to fund development on a more production-ready version. The keyboard itself uses Keychron switches, and the finish is decent, but there are definitely some bugs to work out.
