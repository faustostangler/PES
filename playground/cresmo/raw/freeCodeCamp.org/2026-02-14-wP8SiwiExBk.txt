Para quem não conhece o Homebrew, rapidinho, o que ele faz? Então, a maneira como eu gosto de descrever para pessoas menos técnicas é que é como um gerenciador de pacotes, quer dizer, é como uma App Store, mas para software de código aberto, certo? E se as pessoas sabem o que é um terminal, então eu o descreveria como sendo, você sabe, um gerenciador de pacotes também, certo? Então, se você é um desenvolvedor, se você trabalha com software, se você talvez esteja acostumado a usar o npm ou algo parecido para instalar seu JavaScript ou o pip para instalar seu código Python ou qualquer outra coisa . E se você quiser instalar todos os programas que não vêm de gerenciadores de pacotes baseados em linguagem, se você usa Mac (e um número crescente de pessoas usa Linux), provavelmente vai instalar pelo Homebrew.
