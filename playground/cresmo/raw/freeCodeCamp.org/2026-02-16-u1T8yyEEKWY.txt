Vamos aprender o básico de SQL em menos de 60 segundos. O SQL se comunica com bancos de dados. Imagine um banco de dados como uma planilha gigante. Uma seleção captura dados. Selecionar um nome entre os usuários retorna todos os nomes.

Onde filtra. Adicione a opção onde a idade é superior a 21 anos para obter apenas adultos. O comando Insert adiciona novos dados. Inserir nos usuários os valores de Bo 25. Atualizar alterações nos dados existentes.

Atualize os usuários definindo a idade como igual a 26, onde o nome é igual a Bo. Excluir remove os dados. Excluir da lista de usuários cujo nome seja igual a Bo. Perdido. A junção combina tabelas. Selecione asterisco

de usuários junte pedidos em users.id igual a users.user_id. São as operações de selecionar, onde, inserir, atualizar, excluir e unir. Você acabou de aprender o básico de SQL. Agora
