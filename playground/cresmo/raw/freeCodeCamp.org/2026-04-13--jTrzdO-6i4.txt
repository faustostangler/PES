Então, o que é recursão? Imagine-se entre dois espelhos. Você vê a imagem se repetindo cada vez menor. Recursão é quando uma função chama a si mesma, potencialmente várias vezes, para resolver um problema. Vamos analisar um exemplo prático básico de código em JavaScript onde a recursão é usada para resolver um problema. Neste caso, o

problema é calcular fatoriais. Então, o que é um fatorial? O fatorial é uma forma de multiplicar um número inteiro por todos os números inteiros positivos abaixo dele. Então, qual é o fatorial de três? Podemos calcular o resultado assim: 3 * 2 * 1, que é igual a 6. O

fatorial de 3 é 6. Qual é o fatorial de 5? Podemos calcular o resultado assim: 5 * 4 * 3 * 2 * 1, que é igual a 120. O fatorial de 5 é 120. Você pode ver que esse padrão lógico se repete até que a operação de multiplicação final envolva a multiplicação pelo valor 1. Isso

se refere ao caso base. E quando o caso base é verdadeiro, o padrão lógico precisa parar de se repetir. Portanto, é aqui que o resultado final é calculado, e não queremos mais continuar chamando a função recursiva. Assim, a função recursiva reutilizável para calcular fatoriais se parece com isto. A função chama a si mesma até que o caso base seja verdadeiro, ou seja, quando n for igual a 1.

O resultado final é retornado após ser multiplicado por 1. Portanto, a função continua chamando a si mesma até atingir um caso base, o ponto de parada. Lembre-se: a ausência de um caso base resulta em um loop infinito. Então, isso é recursão, dividir grandes problemas em versões menores de si mesmos.
