Vamos aprender o básico de estruturas de dados em menos de 60 segundos. Os arrays armazenam itens em ordem. Acesse qualquer item instantaneamente pelo seu índice. Listas encadeadas conectam itens. Cada item aponta para o próximo.

Empilhamentos são feitos por ordem de chegada, como uma pilha de pratos. Encaixe, desencaixe. As filas funcionam por ordem de chegada, como uma fila em uma loja. Os mapas de hash armazenam pares de chave-valor. Consulte qualquer valor instantaneamente pela sua chave.

As árvores se ramificam a partir de uma raiz. Ótimo para hierarquias e buscas. Os grafos conectam nós com arestas. Ideal para criar redes de contatos e relacionamentos. São elas: arrays, listas ligadas, pilhas, filas, mapas de hash, árvores e grafos.

Você acabou de aprender o básico sobre estruturas de dados. Agora vá construir alguma coisa.
