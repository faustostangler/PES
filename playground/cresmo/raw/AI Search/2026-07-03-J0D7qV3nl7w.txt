O número de cálculos necessários é astronômico. Atualmente, as GPUs modernas

Essa etapa é, na verdade, muito fácil para a GPU. A verdadeira lentidão não está nesses cálculos feitos por meio de uma rede neural.

O chip precisa buscar todos os valores salvos referentes aos relacionamentos entre cada palavra e como ela se relaciona com todas as outras palavras. Novamente, para uma frase curta, está ótimo. Agora, é claro, a indústria está ciente dessa enorme ineficiência e existem soluções alternativas para isso. Na verdade, o padrão ouro atual para acelerar a geração é algo chamado decodificação especulativa. E a ideia aqui é surpreendentemente simples. Em vez de usar um modelo grande para gerar lentamente cada palavra uma de cada vez, você usa um modelo menor e mais rápido para adivinhar várias palavras à frente. Em seguida, o modelo principal simplesmente

Aqui está uma analogia simples para entender isso. Imagine que você tem um chefe sênior brilhante no trabalho. Ele não é tão inteligente quanto o chefe, deixa passar detalhes e às vezes escolhe as palavras erradas, mas trabalha extremamente rápido. Eis como funciona a decodificação especulativa. Em vez de pedir ao chefe para escrever tudo, você pede ao estagiário para redigir rapidamente um pequeno trecho de texto com antecedência, talvez de cinco a dez palavras. O estagiário entrega este rascunho

Em termos de IA, o modelo maior pode verificar várias palavras adivinhadas pelo modelo menor simultaneamente, porque as GPUs são projetadas para trabalho paralelo. Assim, em vez de usar o modelo grande para escrever lentamente uma palavra de cada vez, usamos o modelo pequeno para adivinhar várias palavras. E então usamos o modelo grande para verificar sua resposta de uma só vez. Mas o que acontece

se o estagiário cometer um erro? Bem, o sistema utiliza uma técnica chamada amostragem por rejeição. O modelo maior analisa o rascunho do estagiário da esquerda para a direita e aceita todas as palavras que estão alinhadas. Mas se o estagiário errar uma palavra, o chefe pega uma caneta vermelha e rejeita essa palavra e tudo o que vier depois dela. Se a palavra estiver errada, tudo o que vier depois dela será rejeitado e o modelo menor começará a partir daí. E o processo se repete várias e várias vezes. Atualmente não existe uma boa solução para a decodificação especulativa, porque um tipo de desenhista é muito cuidadoso, mas muito lento.
