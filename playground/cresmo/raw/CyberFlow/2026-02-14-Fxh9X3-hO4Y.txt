Python para hacking. Comece com "Automatize as Tarefas Chatas" de Al Sweigart. É gratuito, online e ensina Python na prática em semanas, não em meses. Se você já conhece variáveis ​​e loops, pode pular os primeiros capítulos. Comece direto com web scraping, trabalhe com arquivos, analise dados, use expressões regulares e tudo o que você usará constantemente. Assim que

terminar esse livro, pare de fazer tutoriais e comece a construir ferramentas de hacking imediatamente, porque é assim que você realmente aprende. Seu primeiro projeto deve ser um scanner de portas. Parece básico, mas você aprenderá sobre sockets, threads para aumentar a velocidade, tratamento de erros quando as portas são fechadas, formatação de saída, tudo o que é fundamental. Utilize a biblioteca socket do Python para conectar-se a endereços IP em portas diferentes. Envolva o código em um bloco try-except para lidar com portas fechadas de forma adequada.

Adicione multithreading com concurrent.futures para escanear várias portas simultaneamente em vez de esperar 10 minutos por um único IP, e de repente você terá construído algo que realmente funciona e entenderá como o Nmap faz o que faz internamente. O segundo projeto é um enumerador de subdomínios. Você aprenderá a fazer requisições HTTP com a biblioteca requests, pesquisas de DNS com DNS Python, ler listas de palavras linha por linha, lidar com timeouts e exceções quando domínios não existem e gerar arquivos de saída com os resultados. Este artigo ensina como funcionam as ferramentas de enumeração e por que, às vezes, elas não detectam subdomínios.

Geralmente acontece porque a lista de palavras é ruim ou o tempo limite é muito rigoroso. Agora você sabe como resolver isso. O terceiro projeto é um cracker de hash. Leia um arquivo de hashes de senhas, calcule o hash de cada linha de uma lista de palavras com o hashlib usando MD5 ou SHA-256, compare os resultados com o hash desejado e imprima as correspondências. É exatamente assim que o Hashcat funciona conceitualmente, só que muito mais lento porque você não está usando aceleração por GPU, mas você entenderá a lógica e poderá otimizá-la posteriormente com multiprocessamento para usar todos os núcleos da sua CPU . Adicione suporte para hashes com salt

e, de repente, você estará lidando com cenários do mundo real em que as senhas não são mais apenas MD5 bruto. O quarto projeto é um web scraper para OSINT (Inteligência de Fontes Abertas). Use o módulo requests para buscar páginas da web, o BeautifulSoup para analisar HTML e extrair e-mails, números de telefone, links de redes sociais, ou qualquer outra coisa que você esteja procurando. Adicione a biblioteca RE para expressões regulares para encontrar padrões como formatos de e-mail ou números de telefone, salve tudo em um arquivo CSV com a biblioteca CSV do Python e você terá criado uma ferramenta de reconhecimento que realmente encontra informações para engenharia social ou criação de perfis de alvos. É assim que você cria scrapers personalizados quando a estrutura do site de destino não é compatível com ferramentas prontas para uso. O

quinto projeto consiste em automatizar o Nmap com Python. Utilize subprocessos para executar comandos Nmap a partir de scripts Python, analise a saída XML com xml.etree.ElementTree, extraia portas e serviços abertos e alimente outras ferramentas com esses dados automaticamente. Talvez, se a porta 80 estiver aberta, o Nikto ou o GoBuster sejam executados automaticamente.

Se a porta 22 estiver aberta, tente usar as credenciais SSH comuns com o Paramiko. Automatize todo o seu fluxo de trabalho de reconhecimento para que um único script faça o que antes levava uma hora de trabalho manual. É aqui que o Python se torna verdadeiramente poderoso para a programação. Você está orquestrando ferramentas em fluxos de trabalho personalizados que ninguém mais possui. Aprenda a usar essas bibliotecas nessa ordem, pois você as utilizará constantemente. Requests para

interações HTTP, Beautiful Soup para análise de HTML, Scapy para manipulação de pacotes e ferramentas de rede personalizadas, Paramiko para automação de SSH, subprocess para executar comandos do sistema e outras ferramentas, socket para redes de baixo nível, multiprocessamento para velocidade em ataques de força bruta ou quebra de segurança, e RE para padrões de expressões regulares na busca de e-mails, IPs e qualquer coisa com formatos previsíveis.
