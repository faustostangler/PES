So you have sort of free pieces, right? You have your extension and then you have a server that you could set up and then you have whatever API you want to call. So let's say the Gemini API. And traditionally, what you might do is if you want your extension to call the API, you could just have your extension maker request directly to the API. And this is great. But to do this, you actually need the API key to be in your extension and then it's really easy to extract, like we've said. But what we can actually do instead is we can have your extension maker request to the server and then your server can make a request to the Gemini API. And this is good because it means only your server needs to know your API key, your server can make the authenticated request. And it's also really easy for you to add rate limits or block requests.
