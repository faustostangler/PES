So yeah, this is the HTML in Canvas API. It lets you render HTML inside of a Canvas using something like WebGL, WebGPU or context 2D. This means that you can now have traditional form elements like this one, but with really cool like overlays and effects applied. There's a huge number of different use cases for this. If you want to have something like a cool book with a page turning effect, you can have that.

But because this is all the HTML that you know and love, you can even do stuff translate it to Korean using the browser translate. And it's all fully accessible and working as the normal HTML would.
