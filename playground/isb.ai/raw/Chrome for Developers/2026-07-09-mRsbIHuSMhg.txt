Everyone wonder why AI agents are so bad at clicking them on the web? Usually they're just guessing where to click, which we call actuation. It's like filing a toy in a pitch black room, but web MCB changes that. It's a proposed web standard that lets websites handy agents enable directory of exactly what tools are on the page. We do this in two ways. There's the declarative API that lets you turn standard HTML forms into tools just by adding a tool name attribute. Or you can use the imperative API in JavaScript to register custom tools using registered tools. So instead of an AI burning tokens trying to navigate your check out page, it instantly knows how to import your order and submit it securely, no guesswork, no book and steps. The web MCB Origin trial is available for testing in Form 149.
