Fetcham is a browser mediated way to handle Federated identity. It is designed to provide a more convenient and more private identity. Federation flow. The FedCM API is protocol agnostic, and it operates on a different layer from standards like OAuth or SAML. The key innovation of FedCM is that it puts the browser in the middle.

The browser serves as a trusted mediator between the user, the relying party, and the identity provider. In short, to support FedCM, the identity provider needs to serve a well-known file and a set of specific endpoints. If you want to learn more and get started with an implementation, visit google.com.
