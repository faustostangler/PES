Bem-vindos de volta. Configuramos um LLM avaliador básico, mas ainda não podemos confiar totalmente nele. Hoje, vamos garantir que ele concorde com a gente, alinhando e testando. Vamos criar um conjunto de dados, rotular, pedir que o avaliador rotule também, iterar até estarmos alinhados e, depois, testar para consistência. Aviso rápido: neste cenário, nós, desenvolvedores, atuamos como especialistas do domínio para classificar os dados por conta própria, mas, na produção, use especialistas de verdade.

Passo um: crie um conjunto de dados de alinhamento com 30 a 50 pares de entrada e saída. Use logs de produção ou peça a um LLM para gerar dados sintéticos. Queremos 10 exemplos de casos ideais, mas principalmente 20 casos problemáticos para que o avaliador aprenda a identificar erros. Peça ao LLM tanto falhas óbvias, como um slogan tóxico, quanto falhas mais sutis, como um tom inadequado. Vamos rodar o avaliador nos dados que rotulamos e buscar um índice de alinhamento de 85%.

Se ficar abaixo disso, agrupamos os casos de falha, analisamos as justificativas do avaliador e atualizamos nossa rubrica de avaliação e as instruções do sistema para fechar essas lacunas. Você pode pedir a um agente de código para melhorar os prompts, mas atenção: ajustar as instruções para um caso específico pode acabar ajustando demais o avaliador a esse conjunto de dados. Depois de atingirmos nossas metas, para garantir que não foi apenas sorte com esses exemplos, usamos um truque estatístico chamado bootstrapping. Reamostramos aleatoriamente nossos 30 itens com reposição. É como criar novos dados, uma nova versão do cenário, sem trabalho extra de rotulagem.

Casos mais difíceis podem ser selecionados cinco vezes em uma execução, mas, se o índice de alinhamento se mantiver estável ao longo de 10 execuções, nosso avaliador é confiável. Por fim, verificamos a autoconsistência, testando o avaliador várias vezes com exatamente as mesmas entradas. Se a variância for maior que zero, o avaliador está dando respostas diferentes e precisamos ajustar o prompt ou a temperatura. Publicamos o código completo e um artigo sobre isso. Então, bifurque, execute as avaliações e compartilhe seus resultados.
