Instead of asking our agent to look at specific files, we ask you to look at the runtime as DevTools for agents has access to source Maps. It will be able to guide your coding agent to the right file anyway, so we are going with Go to localhost, signup, debug and fix the error when signing up with test and 1234. Using this prompt with my coding agent and DevTools for agents enabled will start a full end to end fixing flow. The agent will open the page in a real Chrome instance. Try to log in, capture any Console logs or network requests, and combine all the pointers to actually fix the code.
