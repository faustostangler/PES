  Context7 resolve isso. É um MCP server open source feito pela Upstash que busca a documentação oficial e atualizada de qualquer biblioteca e entrega pro seu agente de IA antes dele gerar código. Quando você pede pra implementar autenticação com NextAuth, em vez do agente chutar baseado no treinamento ele consulta os docs reais da versão atual. Funciona com Claude Code, Codex, Cursor, Antigravity e qualquer ferramenta que suporte MCP.
   
  O Context7 tem duas partes. O MCP Server que roda em tempo real durante a sessão. Você adiciona "use context7" no prompt e ele busca os docs na hora. E o Skill Wizard que gera skills permanentes a partir da documentação. A skill fica salva e o agente usa toda vez que trabalha com aquela lib sem precisar pedir. Uma consulta pontual vs conhecimento permanente.
   
  A instalação do MCP Server é um comando no Claude Code. Uma linha, reinicia, confirma com /mcp que tá connected. Pra testar manda qualquer prompt e adiciona "use context7" no final. O Claude busca os docs atuais antes de responder e você vê no output que ele consultou o Context7.
   
  O Skill Wizard é onde fica mais poderoso. Roda um comando, ele pergunta qual biblioteca, pra que serve a skill e se tem algum foco específico. Consulta o Context7, puxa os docs atuais e gera um SKILL.md completo com boas práticas, padrões recomendados e exemplos. No final pergunta onde instalar e detecta quais ferramentas você tem: Claude Code, Cursor, Codex, Antigravity. Seleciona vários ao mesmo tempo. Uma skill, todas as ferramentas.
   
  No vídeo crio 3 skills que uso no dia a dia. Next.js App Router com foco em server components, server actions, middleware e caching. Prisma ORM com foco em schema design, queries, relations e migrations. Tailwind CSS v4 com a nova sintaxe e configuração. 3 skills em menos de 5 minutos, cada uma com documentação atualizada, prontas pra usar em qualquer projeto.
   
  Depois das skills instaladas o agente carrega automaticamente quando detecta que você tá trabalhando com aquela lib. Sem precisar pedir. Coda normalmente e ele detecta Next.js, Prisma e Tailwind no prompt, carrega as 3 skills e gera código seguindo os padrões atuais de cada uma. A diferença: sem skills ele gera baseado no treinamento que pode ter meses de atraso. Com skills do Context7 ele segue os docs da versão atual.
   
  Mostro também como gerenciar as skills instaladas, buscar skills prontas da comunidade e quando usar MCP em tempo real vs Skill Wizard. MCP pra consulta pontual e exploratória com lib que você não usa sempre. Skill Wizard pra lib que usa em todo projeto e quer que o agente sempre siga as boas práticas.
