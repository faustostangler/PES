O Codex local com Ollama resolve esses dois cenários ao mesmo tempo.
  
  O recurso central é simples: o Codex CLI suporta apontar pra um endpoint OpenAI-compatible, e o Ollama serve qualquer modelo open source nesse padrão. O comando ollama launch codex --model gpt-oss:20b cuida de tudo automaticamente: verifica se o modelo tá baixado, faz download se precisar, sobe o servidor local do Ollama, e inicia o Codex já configurado apontando pra ele. Sem flag adicional, sem editar arquivo, sem variável de ambiente. Um comando, e o Codex aparece com header indicando "local via Ollama".
  
  Os modelos recomendados pra rodar como cérebro do Codex são vários, cada um com perfil diferente. O gpt-oss:20b é o equilíbrio padrão, recomendado pra começar. O gpt-oss:120b entrega máxima qualidade se a máquina suporta. O qwen3-coder:30b é especialista em código e costuma performar muito bem em refactor. O deepseek-coder:16b é o mais rápido pra quem quer respostas em segundos. O gemma3:27b é alternativa generalista boa. Trocar entre eles é trivial: roda o mesmo comando trocando o nome do modelo.
  
  Pra quem quer mais controle, existe o caminho do config.toml. No arquivo ~/.codex/config.toml dá pra definir profiles nomeados, cada um apontando pra um modelo específico do Ollama. Depois é só rodar codex --profile qwen-coder ou codex --profile deepseek e o Codex já abre com o modelo escolhido. Útil quando você usa modelos diferentes pra tarefas diferentes.
  
  O combo Codex + Ollama tem casos de uso óbvios: refactor de projetos privados sem mandar uma linha pra cloud, code review automatizado em código sob NDA, geração de boilerplate offline em viagem ou rede ruim, e qualquer fluxo onde privacidade ou custo são bloqueios. Não substitui Codex cloud em todo cenário, mas resolve uma fatia grande do uso diário.
  
  Existe um bônus que poucos sabem: o ollama launch funciona também com outros coding agents. Tem ollama launch claude pro Claude Code, ollama launch openclaw pro OpenClaw, ollama launch hermes pro Hermes Agent, ollama launch opencode pro OpenCode e ollama launch codex-app pro Codex App desktop. Mesmo padrão, mesmo nível de simplicidade, todos rodando local com qualquer modelo do Ollama.
  
  Quando precisar voltar pro Codex cloud, basta rodar codex sem flag e ele volta pro modo padrão. Você usa os dois lado a lado conforme a tarefa: cloud quando precisa do modelo mais forte, local quando precisa de privacidade, velocidade ou economia.
  
  Pra usar bem o setup, vale ter Ollama instalado, Codex CLI instalado via npm, e GPU decente pra rodar modelos de 20B ou maior com performance. Mas mesmo CPU dá conta dos modelos menores, então não tem barreira absoluta.
