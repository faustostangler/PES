  As 4 features são: Server Preview, Code Review, PR Monitoring com Auto-Fix e Auto-Merge, e Session Mobility. Vou mostrar cada uma na prática.
  
  Começo criando um app de gerenciamento de tarefas do zero com Next.js, TypeScript e Tailwind. O Claude Code monta o projeto, inicializa o git e já abre o preview embutido direto no app. Essa é a primeira feature: o Server Preview. O Claude roda o servidor, abre o app dentro do próprio Desktop e testa sozinho. Quando peço pra adicionar data de vencimento com badge de "Atrasada" e animações, ele implementa, roda o preview e verifica se tá tudo funcionando sem eu precisar abrir navegador nenhum. Ativei a verificação automática, então depois de cada edição ele testa sozinho e corrige o que encontrar. Dá até pra clicar num elemento visual no preview e dar feedback direto tipo "esse botão tá pequeno", e ele ajusta na hora.
  
  A segunda feature é o Code Review. Depois de implementar drag and drop, exportação e importação de JSON, clico no botão "Review code" na barra superior. O Claude usa 4 agentes em paralelo pra analisar os diffs e deixa comentários inline no código. O review foca no que importa: erros de compilação, bugs de lógica, vulnerabilidades de segurança. Ele não enche o saco com estilo ou formatação. Você pode responder aos comentários e pedir pra ele corrigir os problemas que ele mesmo encontrou.
  
  A terceira feature é a mais impressionante: PR Monitoring com Auto-Fix e Auto-Merge. Crio uma branch, implemento toggle de tema claro e escuro, faço commit e abro um Pull Request pro GitHub. O Claude monitora os checks de CI em tempo real. Se o CI falhar, ele lê o output do erro, corrige o código e faz push automático. Quando todos os checks passam, ele mergeia sozinho. Mostro isso ao vivo: introduzo um erro de tipagem de propósito, o CI falha, o Claude detecta, corrige e faz push em segundos. E enquanto ele monitora um PR em background, eu trabalho em outra feature numa branch separada.
  
  A quarta feature é Session Mobility. Você pode mover sua sessão entre o Desktop, o CLI no terminal, o navegador e até o celular. Todo o contexto vai junto. Mostro clicando em "Continue with Claude Code on the web" e a sessão inteira vai pro cloud. Também mostro o caminho inverso: abrir no CLI e mandar pro Desktop com o comando /desktop.
  
  No final menciono o Claude Code Security que a Anthropic lançou no mesmo dia. É uma ferramenta separada que escaneia seu código buscando vulnerabilidades usando o Opus 4.6. Não é pattern matching como ferramentas tradicionais, ele raciocina sobre o código como um pesquisador de segurança. O time da Anthropic encontrou mais de 500 vulnerabilidades em projetos open-source que existiam há décadas. Por enquanto tá em preview limitado pra Enterprise e Team.
  
  Isso não é mais um assistente de código. É um workflow completo: cria, testa, revisa, corrige e mergeia. Tudo numa interface só.
