  Primeiro explico o que são Skills no Antigravity. Uma skill é um pacote de instruções especializadas que a IA carrega somente quando precisa. Diferente de um system prompt que fica o tempo todo consumindo contexto, a skill é inteligente e só ativa quando faz sentido. A estrutura é simples: um arquivo Markdown chamado SKILL.md com instruções e opcionalmente scripts em Python ou Bash que a IA pode executar. Sem skills o Antigravity dá respostas genéricas e código de tutorial. Com skills vira um especialista sob demanda com código de produção e padrões profissionais.
  
  Mostro o repositório Antigravity Awesome Skills com quase 8 mil stars e 968 skills battle-tested. Funciona no Antigravity, Claude Code, Cursor, Gemini CLI. Tem skills oficiais da Anthropic, do Google, da Vercel e da Supabase. Instalação com um comando: npx antigravity-awesome-skills. Ele clona tudo pra pasta .agent/skills/ e pronto.
  
  Pra testar de verdade, construo um app full-stack de gerenciamento de tasks usando só 4 skills.
  
  A primeira skill é @brainstorming. O próprio repositório diz pra sempre começar com ela antes de construir qualquer coisa. Ela transforma a IA num arquiteto de produto que pensa antes de codar. Faz perguntas estruturadas, valida requisitos e gera um spec completo com decisões técnicas justificadas, estrutura de pastas e modelagem de dados.
  
  A segunda skill é @backend-dev-guidelines. Pego o plano que o brainstorming criou e executo o backend. A diferença é brutal: middleware de auth separado, rotas organizadas, validação de input, error handling. Padrões profissionais de Node.js e Express que sem a skill seriam código de tutorial. API Express com SQLite funcionando com autenticação JWT.
  
  A terceira skill é @react-best-practices. React moderno com padrões de produção. Context API pro auth, service layer separado, componentes organizados. Login funcionando, dashboard com stats, CRUD completo de tasks com filtros por status e prioridade. Frontend e backend conversando perfeitamente.
  
  A quarta skill é @api-security-best-practices. A cereja do bolo. Peço pra skill auditar o código que o próprio Antigravity criou. E ela encontra problemas: rate limiting faltando, validação de input incompleta, headers de segurança. Não só encontra como dá o fix pra cada um seguindo padrões OWASP. A skill de segurança auditou o código que as outras skills criaram. Sem ela esses problemas iriam pra produção.
  
  Sou honesto sobre o lado negativo. Instalar todas as 900+ skills de uma vez tem um custo: o Antigravity carrega os metadados de todas no início da sessão. Mais skills, mais tokens, mais chance de ativar skill errada. O próprio repositório recomenda usar Bundles, que são pacotes curados por especialidade. Instala o repositório completo pra ter tudo disponível mas foca nas skills do bundle do seu projeto.
  
  O poder real não tá em ter 900 skills. Tá em usar as certas na hora certa. Com 4 skills saí do zero a um app full-stack planejado, com backend profissional, frontend com padrões de produção e segurança auditada.
