  Diferente do Claude Design que é pago, tem quota limitada e só funciona com Opus 4.7, o Open Design vem com 31 skills prontas, 72 design systems de marcas reais (Linear, Stripe, Vercel, Airbnb, Notion, Apple, Spotify, Figma, Tesla e mais), suporta 10 coding agents diferentes (Claude Code, Codex, Cursor, Gemini, OpenCode), e ainda permite BYOK pra plugar DeepSeek, Groq, OpenRouter ou vLLM próprio.
  
  Se você usa Claude Design e cansou da quota esgotando rápido (no plano Max de 200 dólares um único projeto consome metade da quota semanal), ou se nunca pagou Anthropic e quer testar uma plataforma de design com IA do mesmo nível, esse vídeo é pra você. Cubro instalação, tour completo da plataforma, 3 projetos reais ao vivo (landing page SaaS, pitch deck magazine, app mobile com frame de iPhone), e a feature bônus que ninguém mostrou: importação de ZIP exportado do Claude Design pra continuar editando localmente.
  
  A instalação leva 4 comandos: git clone do repo, corepack enable, pnpm install, pnpm tools-dev run web. O daemon escaneia seu PATH automaticamente e detecta os coding agents instalados. Sem API key, sem config, abre o browser com a interface limpa parecida com Claude Design.
  
  A interface tem skill picker com 31 skills organizadas por cenário (design, marketing, operation, engineering, product, finance, hr, sale, personal). Cada skill é uma pasta com SKILL.md, template e checklist, e você pode criar suas próprias. Tem design system picker com 72 sistemas reais de marcas conhecidas, cada um com cores, tipografia, espaçamento e componentes definidos. Seleciona Linear e o design sai com a cara do Linear.
  
  Tem agent picker pra escolher qual coding agent vai rodar, e direction picker com 5 direções visuais prontas pra quando você não tem marca definida: Editorial Monocle, Modern Minimal (Linear/Vercel), Tech Utility (Bloomberg, monospace), Brutalist e Soft Warm (Notion, Apple Health). Cada direção tem paleta OKLch e font stack determinísticos, zero AI slop.
  
  A primeira demo é uma landing page SaaS pra um produto chamado FlowEngine usando o design system do Stripe. Mostro como funciona o question form (formulário ANTES de gerar pra forçar clareza sobre superfície, público-alvo, tom e contexto de marca), o TodoWrite streaming (plano aparece ao vivo), o 5-dimension critique (auto-crítica em filosofia, hierarquia, execução, especificidade e contenção; se nota abaixo de 3/5 em qualquer dimensão refaz), e o preview no iframe com export pra HTML, PDF, PPTX, ZIP ou Markdown.
  
  A segunda demo é um pitch deck de 8 slides usando a skill guizang-ppt no modo magazine, com capa cinematográfica, slides de problema, solução, mercado, modelo de negócio e ask. Estilo editorial com WebGL no hero, navegável com setas. A terceira demo é um protótipo mobile com 3 telas no frame real do iPhone 15 Pro (com Dynamic Island e status bar), navegação clicável entre dashboard, editor de workflow visual e detalhes de execução.
  
  O Open Design é construído em cima de 4 projetos open source unificados: Huashu Design (filosofia anti-AI-slop), Guizang PPT (modo deck magazine), Open CoDesign (patterns de UX) e Multica (arquitetura daemon). Apache 2.0, sem lock-in, sem cloud obrigatório.
  
  No final apresento comparativo completo entre Claude Design e Open Design lado a lado, e dou recomendação clara de quando usar cada um.
