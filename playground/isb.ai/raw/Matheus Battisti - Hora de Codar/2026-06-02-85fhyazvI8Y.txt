  A primeira sacada é o Claude Code apontando pro DeepSeek. O Claude Code CLI é gratuito (instala via npm com npm install -g @anthropic-ai/claude-code) e aceita endpoint Anthropic-compatible via settings.json. Você cria ~/.claude/settings.json com ANTHROPIC_AUTH_TOKEN da DeepSeek, ANTHROPIC_BASE_URL apontando pro endpoint deles e ANTHROPIC_MODEL como deepseek-v4-pro. Pronto. Claude Code abre apontado pro DeepSeek sem nem precisar de conta Anthropic.
  
  A segunda sacada é o DeepSeek V4 Pro entregando qualidade real. Score de 96.4 no LiveCodeBench, mesmo nível do Opus em 80% das tarefas, com cache automático que deixa loops 120 vezes mais baratos. Preço de input em 0.44 dólar por milhão e output em 0.87 dólar por milhão (vs Opus que cobra 5 e 25 dólares respectivamente). Em uso médio de dev diário, 25 dólares cobrem o mês inteiro contra 200 do Claude Max.
  
  A terceira sacada é o OpenCode com DeepSeek como alternativa zero-vínculo Anthropic. OpenCode é open source, instala com curl, e aceita DeepSeek nativamente via opencode.json. Mesma chave do DeepSeek serve pros dois agentes. Tem suporte MCP próprio que resolve a limitação do Claude Code via DeepSeek (que não suporta MCP server tools).
  
  A quarta sacada é o AGENTS.md como ponte entre os dois agentes. AGENTS.md é convenção aberta da indústria (página oficial em agents.md), lida nativamente por OpenCode, Codex, Aider, Zed e Warp. É um README pra agentes de IA: documenta stack, estrutura, banco, autenticação e regras importantes. Você pede pro Claude Code criar o AGENTS.md ao terminar uma sessão, e o OpenCode lê o arquivo na próxima sessão e entra no projeto sem precisar de explicação.
  
  Mostro também as limitações honestas. DeepSeek não suporta vision, parallel tool use, MCP server tools no Claude Code via DeepSeek, e cache da Anthropic. Funciona normal pra file reading/editing/writing, bash, git operations, subagents, loops autônomos e thinking mode.
  
  No final apresento comparativo de custo real em 3 cenários: uso leve, médio e pesado. Em todos os cenários a economia fica entre 70% e 96% comparado ao Claude Max, e nenhum esbarra em rate limit semanal.
  
  Use Claude Code + DeepSeek se já tem o Claude Code instalado e quer UX familiar. Use OpenCode + DeepSeek se quer zero vínculo com Anthropic ou precisa de MCP. Use os dois no mesmo projeto com AGENTS.md como ponte e tem o melhor dos mundos.
