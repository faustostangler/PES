  O GLM-5 é o modelo da Z.ai que tem 744 bilhões de parâmetros no total mas só ativa 40 bilhões por vez usando arquitetura Mixture of Experts. Ele alcançou 92.7% no AIME 2026, 86% no GPQA-Diamond e 77.8% no SWE-bench Verified. É o modelo open source mais bem posicionado no LMArena Text Arena, competindo com modelos fechados que custam dezenas de dólares por milhão de tokens. E a licença é MIT, ou seja, totalmente aberta.
  
  A Modal está oferecendo um endpoint gratuito do GLM-5 até 30 de abril de 2026. O limite é 1 request concorrente sem limite de tokens, rodando em 8 GPUs B200 com SGLang a uma velocidade de 30 a 75 tokens por segundo. Você cria conta na Modal, gera o token na página do GLM-5 e já pode usar via API compatível com OpenAI.
  
  Começo mostrando como testar direto via cURL sem instalar nada. Faço uma chamada simples pedindo um componente React, depois uma com streaming pedindo uma API REST completa, e mostro como listar os modelos disponíveis no endpoint. Tudo funciona com o formato padrão da OpenAI, então qualquer ferramenta que aceita endpoint customizado funciona com o GLM-5 da Modal.
  
  Depois parto pra integração com o OpenClaw. Mostro o passo a passo completo: instalar o OpenClaw, exportar o token como variável de ambiente, configurar o openclaw.json apontando pro endpoint da Modal com custo zero, validar com o openclaw doctor e iniciar o gateway. Explico cada campo da configuração incluindo o maxConcurrent em 1 porque o endpoint free só aceita 1 request por vez. Mostro também como trocar de modelo na sessão com o comando /model e como verificar qual modelo está ativo.
  
  Na configuração avançada, mostro como adicionar fallbacks pra caso o GLM-5 fique indisponível. O modelo principal é o GLM-5 via Modal de graça, e se ele cair, o OpenClaw automaticamente redireciona pra Gemini Flash-Lite ou GPT-5 Nano via OpenRouter. Assim você tem redundância sem ficar na mão.
  
  Mostro também como usar o GLM-5 via Python com requests pra quem quer integrar em projetos próprios, e uma alternativa rápida usando Ollama Cloud com um único comando que lança o OpenClaw direto com o GLM-5 sem configuração manual.
  
  O custo total dessa estrutura é zero. O GLM-5 é gratuito via Modal até abril de 2026. O OpenClaw é open source. Você só precisa de uma máquina pra rodar o agente. É o setup mais barato possível pra ter um agente de IA autônomo rodando com um modelo frontier.
