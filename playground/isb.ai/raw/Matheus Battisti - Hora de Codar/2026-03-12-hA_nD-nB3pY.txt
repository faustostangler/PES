  O Superpowers foi criado pelo Jesse Vincent, lenda no open source e fundador da Keyboardio. O que ele fez foi transformar a experiência dele com Claude Code numa série de skills que o Claude é obrigado a seguir. Não são sugestões. São lei.
  
  O workflow tem 7 fases. Na primeira o Claude não sai codando. Ele para e te faz perguntas. Refinamento socrático. Só depois de você aprovar o design ele segue. Na segunda ele cria um workspace isolado num branch novo com git worktrees. Na terceira gera um plano de implementação com tarefas de 2 a 5 minutos cada, escritas pra qualquer um conseguir seguir. Na quarta ele despacha cada tarefa pra um subagente separado e faz code review de cada uma. Tech lead gerenciando júniores. Na quinta força TDD: se o Claude tenta escrever código antes do teste, a skill faz ele deletar e recomeçar. Na sexta faz code review entre tarefas e issues críticos bloqueiam o progresso. Na sétima verifica testes, oferece merge ou PR, e limpa o worktree.
  
  O que torna isso diferente de colar um mega-prompt é o sistema de enforcement. Quando o plugin carrega a primeira instrução é: você tem Superpowers, se existe uma skill pra algo, você é obrigado a usá-la. O Jesse testou com cenários de pressão psicológica pra garantir que as skills resistiriam. Usou princípios de persuasão do Cialdini: autoridade, comprometimento, escassez. E a cada falha fortalecia as instruções. Engenharia de prompts em outro nível.
  
  Instalação com dois comandos no marketplace oficial. Reinicia o Claude Code e o Superpowers se ativa automaticamente.
  
  Na demo crio um app estilo Google Keep pra captura rápida de pensamentos. Fullstack com Next.js 15, Tailwind, API routes, SQLite com Prisma. Cards coloridos tipo post-it com título opcional, tags pra organizar, busca full-text instantânea, fixar pensamentos no topo, dark mode. Tudo local sem serviço externo.
  
  Mostro o brainstorming ao vivo onde o Claude faz perguntas em vez de codar. Depois o plano sendo gerado com tarefas pequenas e verificáveis. Depois a execução com TDD real: teste primeiro, falha vermelho, código mínimo, passa verde, commit atômico. O subagente implementa e o Claude principal faz code review. No final todos os testes passando e o app funcionando completo no browser.
  
  Tem mais dentro do plugin: Systematic Debugging com 4 fases pra causa raiz, Writing Skills que ensina o Claude a criar novas skills com TDD pra skills, Parallel Agents pra múltiplos subagentes simultâneos, e Superpowers Chrome pra controle do navegador via DevTools.
  
  O Superpowers resolve o maior problema do vibe coding: a falta de disciplina. Usar IA pra codar sem metodologia é dar Ferrari pra alguém sem carteira. Rápido é. Mas a chance de bater é enorme. O Superpowers é a carteira de motorista.
