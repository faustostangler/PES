  Channels é uma feature nova do Claude Code que transforma apps de mensagem em controle remoto pro seu terminal. Você roda o Claude Code com a flag --channels, isso sobe um servidor MCP que faz ponte entre o Telegram ou Discord e a sessão ativa. Manda mensagem no Telegram, o MCP injeta como evento na sessão, o Claude executa no computador local e responde de volta no chat. Tudo roda na sua máquina. Seu código não sai do computador. O Telegram é só a interface.
  
  No vídeo mostro a configuração completa do zero. Instalar o Bun que é o runtime JavaScript que a Anthropic usa. Criar o bot no Telegram pelo BotFather com nome e username. Instalar o plugin oficial do Telegram no Claude Code pelo marketplace. Configurar com o token. Iniciar com a flag --channels. Parear pelo Telegram mandando mensagem pro bot e recebendo o código de 6 dígitos. Configurar allowlist pra segurança. Todo o processo leva menos de 5 minutos.
  
  Depois da configuração mando tarefas reais pelo Telegram pra demonstrar o poder da feature. Criar um projeto Node.js com Express e TypeScript do zero com API REST de tarefas. Corrigir um bug específico onde a rota DELETE não retornava 404 pra IDs inexistentes. Gerar um relatório em markdown e receber de volta pelo Telegram como documento. Mandar screenshot de um erro pelo celular e o Claude analisar e corrigir. O plugin suporta envio de arquivos nos dois sentidos com limite de 50MB.
  
  Explico a diferença entre as 3 formas de controlar o Claude remotamente que a Anthropic oferece agora. Channels conecta Telegram e Discord ao terminal pra devs que querem executar código. Dispatch controla o Cowork pelo app mobile pra knowledge workers que mexem em arquivos e planilhas. Remote Control usa o app do Claude no celular como interface mostrando o terminal completo. Channels é o mais flexível pra dev porque a interface é natural: você manda mensagem como se fosse pra um colega de trabalho.
