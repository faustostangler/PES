  A maior novidade é o Computer Use. O Claude Code e o Cowork agora controlam o desktop nativamente. Mouse, teclado, screenshots. Sem setup, sem Docker, sem API separada. O Claude segue uma hierarquia: primeiro tenta connectors como Slack e Google Calendar, depois ferramentas nativas como bash e gh CLI, e por último Computer Use controlando a tela como um humano. Ele tira screenshot, analisa o que tá vendo, decide clicar ou digitar, executa e tira outro screenshot pra verificar. Combinado com Dispatch você manda uma tarefa pelo celular e o Claude controla o desktop de casa enquanto você tá fora. Por enquanto só macOS mas Windows tá confirmado.
   
  Cowork Projects trouxe workspaces isolados dentro do Cowork. Antes tudo era uma sopa misturando contexto de projetos diferentes. Agora cada projeto tem sua pasta local conectada, instruções próprias funcionando como system prompt, memória isolada que não vaza entre projetos, e scheduled tasks dentro do projeto. Dá pra criar do zero, importar de um chat existente, ou conectar uma pasta do computador. Cada workspace é completamente independente.
   
  A versão 2.1.81 do Claude Code veio com mudanças grandes. Opus 4.6 agora tem 64k tokens de output por padrão e o máximo subiu pra 128k tanto pro Opus quanto pro Sonnet 4.6. Na prática o Claude pode gerar arquivos muito maiores numa única resposta sem cortar no meio. Componentes de 500 linhas, relatórios completos, migrações inteiras de uma vez. O comando /copy agora aceita índice pra copiar respostas anteriores específicas. Nova configuração allowRead no sandbox pra re-liberar leitura dentro de áreas bloqueadas. Voice mode ganhou 10 idiomas novos totalizando 20 suportados. Flag --bare pra chamadas scriptadas que pula hooks, plugins e skills. Comando /reload-plugins pra ativar plugins novos sem reiniciar. Variável ${CLAUDE_SKILL_DIR} pra skills referenciarem o próprio diretório. E vários fixes importantes incluindo o auto-updater que consumia dezenas de GB de memória e o --resume que cortava histórico.
   
  Channels é a feature que conecta o Claude Code ao Telegram ou Discord via MCP. Você instala o plugin, cria um bot no Telegram pelo BotFather, configura o token e roda com a flag --channels. Manda mensagem no bot e o Claude Code responde com acesso ao codebase. Funciona como controle remoto pelo celular via chat. A diferença pro Dispatch é que Dispatch usa o app da Anthropic e Channels funciona por qualquer plataforma de chat via MCP.
   
  A direção é clara. A Anthropic tá expandindo o Claude Code pra além do terminal. Desktop com Computer Use, celular com Dispatch e Channels, workspaces persistentes com Cowork Projects, output massivo com 128k tokens. Cada semana ele fica mais agente e menos chatbot. Quem usa Claude Code no dia a dia precisa acompanhar essas mudanças porque o ritmo de atualizações não tá diminuindo.
