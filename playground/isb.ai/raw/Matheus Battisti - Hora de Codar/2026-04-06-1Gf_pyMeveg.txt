  Quando você pede algo complexo pro Claude Code, tipo migrar banco, adicionar auth ou refatorar sistema de pagamentos, ele começa a codar direto. Às vezes acerta, às vezes faz besteira nos primeiros arquivos e o resto cascata. O Plan Mode local com Shift+Tab ajuda mas você vê o plano num textão no terminal. Difícil revisar, difícil comentar em partes específicas, difícil iterar. Ultraplan resolve os dois problemas: planeja com mais profundidade usando Opus 4.6 na cloud e te dá uma interface no browser pra revisar cada seção do plano antes de executar.

  O fluxo funciona em 4 etapas. Você pede o ultraplan no terminal com /ultraplan seguido da descrição do que quer. O Claude Code envia pra cloud e abre uma sessão de planejamento com Opus 4.6 enquanto seu terminal fica livre pra continuar codando. Quando o plano fica pronto você abre no browser e tem o plano completo estruturado por seções com comentários inline, reações com emoji, outline lateral pra navegar e a possibilidade de pedir revisões quantas vezes quiser. Depois de aprovar você escolhe executar na cloud com PR direto no GitHub ou mandar pro terminal local.
   
  A interface de revisão no browser é o diferencial. Você seleciona um trecho do plano e comenta como faria num Google Doc. Pode aprovar seções individuais, marcar preocupações, pedir mudanças específicas como trocar um campo do schema ou mudar a lógica de um componente. Itera quantas vezes quiser até o plano estar perfeito. Só depois o agente escreve código.
   
  No vídeo demonstro com um projeto real: o PensaAí, um app de reflexão que já tem auth, desafios e likes. Peço uma feature complexa de gamificação que toca muitos arquivos. Novas tabelas no Drizzle pra badges e user_badges. 6 badges com critérios diferentes: Primeiro Passo pela primeira reflexão, Consistente por 7 dias seguidos, Pensador por 30 reflexões, Popular por 10 likes recebidos, Explorador por participar de 3 desafios e Veterano por conta com mais de 30 dias.
   
  Além das tabelas o pedido inclui página de conquistas mostrando todos os badges ganhos e bloqueados, componente de badge com ícone, nome e barra de progresso, verificação automática via server action que checa e desbloqueia badges ao criar reflexão, receber like ou entrar em desafio, notificação toast quando desbloqueia um badge novo e badge counter no perfil. Tudo seguindo o visual dark mode do projeto existente.
   
  Mostro o plano sendo gerado na cloud enquanto o terminal fica livre, a revisão no browser comentando inline, pedindo ajustes e aprovando. Depois a execução seguindo o plano aprovado e o resultado final com a página de conquistas funcionando, badges desbloqueando e toast aparecendo.
   
  Ultraplan e Plan local se complementam. O Plan local com Shift+Tab é mais rápido e funciona no terminal pra tarefas simples e médias. O Ultraplan roda na cloud com mais profundidade, tem interface de revisão no browser e é melhor pra mudanças que tocam 5 ou mais arquivos, migrações, features que envolvem auth mais banco mais frontend mais API e qualquer refatoração grande. A regra é simples: se dá medo de mandar o agente fazer direto, usa ultraplan.
   
  Pra usar precisa de Claude Code atualizado, conta no Claude Code on the web e repositório no GitHub. Se já tem plano Pro ou Max, já tem acesso.
