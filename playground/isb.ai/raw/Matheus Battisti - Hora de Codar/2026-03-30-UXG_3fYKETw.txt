  O problema que esse pipeline resolve é simples: quando você pede pro Claude Code construir um app, o visual sai genérico. Cards básicos, cores padrão, tipografia sem personalidade. É funcional mas é AI slop. E quando você desenha no Stitch, o design fica bonito mas não tem as funcionalidades certas porque o Stitch não sabe o que o app precisa fazer. Esse pipeline conecta os dois: o PRD é a fonte da verdade pra funcionalidades e o Stitch é a fonte da verdade pro visual. O Claude Code junta os dois.
   
  O primeiro passo é gerar o PRD no Claude Code. Descreve o produto em linguagem natural e o Claude gera um Product Requirements Document completo com visão do produto, personas, funcionalidades detalhadas por tela, estrutura dos dados, regras de negócio e critérios de aceite. Esse documento vira o contrato de funcionalidades que o Claude Code vai consultar na hora de construir.
   
  O segundo passo é pedir pro Claude Code gerar prompts otimizados pro Stitch. Como o Claude já conhece o PRD, os prompts visuais refletem as funcionalidades. O prompt do menu já vai ter os campos certos, o do carrinho vai ter o campo de mesa, o da cozinha vai ter os status corretos. São prompts de design visual rico, não funcional, prontos pra copiar e colar no Stitch.
   
  O terceiro passo é abrir o Stitch e colar os prompts. Cada prompt gera uma tela. Ajusta o que precisar com texto ou voice mode que permite iterar falando. O resultado são telas com design profissional que seguem a estrutura do PRD sem você ter pensado em layout.
   
  O quarto passo é conectar Stitch ao Claude Code via MCP. Instala as Stitch Skills oficiais e configura o MCP server. Quando reinicia o Claude Code ele tem acesso direto ao projeto do Stitch, consegue puxar telas, design system, cores, fontes e espaçamentos.
   
  O quinto passo é o Claude Code construir. Ele lê o PRD pra funcionalidades e regras, puxa o design system e os layouts do Stitch via MCP, e implementa tudo junto. O tailwind.config recebe as cores exatas do Stitch. Os componentes seguem o layout das telas. As funcionalidades seguem o PRD. O resultado é um app com design profissional e funcionalidades completas.
   
  No vídeo construo o CaféMenu, um cardápio digital de cafeteria. O cliente acessa pelo celular via QR code na mesa, navega pelos produtos organizados por categoria, monta o pedido, informa o número da mesa e envia. A cozinha recebe os pedidos em tempo real num painel com status que avança de novo pra preparando pra pronto. Stack com React, Vite, TypeScript e Tailwind. Dados no localStorage sem backend.
   
  Mostro o pipeline inteiro dos 5 passos e no final faço a demo completa: pedido no celular aparecendo no painel da cozinha em tempo real. Design do Stitch, funcionalidades do PRD, código do Claude Code. Tudo conectado.
