  Nesse vídeo eu explico o que é o WebMCP, por que é diferente do MCP que a gente já conhece, e mostro na prática criando um e-commerce completo com tools que a IA consegue usar.
  
  Primeiro explico o problema que o WebMCP resolve. Hoje quando um agente de IA precisa fazer algo num site, ele funciona como um cego no computador. Tira screenshot, manda pra um Vision Model, tenta adivinhar onde tá o botão, simula clique, e se erra repete tudo. Resultado: 45% de acurácia, custo alto com tokens de imagem, lento e frágil. Mudou um botão de lugar e o agente quebra.
  
  O WebMCP resolve isso de um jeito elegante. Ao invés do agente adivinhar o que o site faz, o site conta pra ele. É uma API nova do navegador que permite que qualquer site exponha tools, funções JavaScript estruturadas com nome, descrição e parâmetros, que agentes de IA descobrem e chamam diretamente. Como um menu de serviços invisível que só a IA enxerga. Resultado: acurácia perto de 98%, redução de 67% no custo de tokens e latência muito menor.
  
  Explico a diferença crucial entre WebMCP e MCP. O MCP da Anthropic é protocolo de backend, você sobe um servidor em Python ou Node e a IA se conecta. O WebMCP roda dentro do navegador, no client-side, no JavaScript do frontend. Não precisa de servidor. A página web vira o servidor. E os dois são complementares.
  
  Mostro as duas formas de implementar. A API Declarativa é a mais simples: você pega um formulário HTML que já existe e adiciona três atributos. O browser transforma automaticamente numa tool estruturada. A API Imperativa é via JavaScript com navigator.modelContext.registerTool(), pra quando precisa de mais controle e lógica dinâmica.
  
  Na demonstração prática criei a TechStore, uma loja fictícia com 6 produtos. Visualmente é um e-commerce normal. Mas quando abro a extensão Model Context Tool Inspector do Google, aparecem 8 tools registradas: busca de produtos, newsletter, carrinho, favoritos, quantidade. Executo as tools ao vivo pela extensão e a UI inteira reage. Adiciono produto no carrinho, favorito, busco, tudo com uma chamada de função. Zero screenshot, zero adivinhação.

E pra acessibilidade é uma evolução enorme pra tecnologias assistivas.
