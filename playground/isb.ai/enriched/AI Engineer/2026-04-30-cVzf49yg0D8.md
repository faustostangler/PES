# Engenharia de Agentes Conversacionais Multimodais: Da API de Interações ao Gemini Live

## Contexto e Visão Geral

Na conferência de engenharia de inteligência artificial de 2026, **Philipp Schmid** e **Thor Schaeff** (Torsten Schaeff), especialistas em experiência do desenvolvedor na **Google DeepMind**, apresentaram os avanços arquiteturais para a criação de agentes conversacionais utilizando os ecossistemas do **Google AI Studio** e das APIs **Gemini**. O workshop abordou a migração das chamadas tradicionais de geração de conteúdo para a nova **Interactions API**, o gerenciamento de estado no servidor (_server-side state_) e os protocolos de comunicação em tempo real via _WebSockets_ no **Gemini Live**.

A apresentação enfatizou a transição de protótipos de chat isolados para sistemas autônomos de engenharia de software dotados de ferramentas de leitura/escrita de arquivos, execução de comandos de terminal, fundamentação multimodal (_grounding_) e integração com servidores **MCP** (_Model Context Protocol_).

---

## 1. A Nova Interactions API e Gerenciamento de Estado no Servidor

Lançada em versão beta para substituir gradualmente a API tradicional de geração de conteúdo (_Generate Content API_), a **Interactions API** padroniza a comunicação entre modelos de linguagem e agentes autônomos sob uma interface unificada.

### 1.1 Blocos de Conteúdo Unificados e Protocolo SSE

A nova especificação adota um formato estruturado onde todas as entradas e saídas seguem uma tipagem homogênea, abrangendo:
* **Chamadas de Função (_Function Calling_)**: Representação explícita de nomes de funções, argumentos em JSON e resultados retornados.
* **Assinaturas de Raciocínio (_Thinking Signatures_)**: Exposição dos passos cognitivos intermediários gerados pelo modelo antes da resposta final.
* **Mídia Multimodal**: Suporte nativo a texto, áudio, vídeo e imagens no mesmo fluxo de requisição via _Server-Sent Events_ (SSE).

### 1.2 Estado no Servidor e Otimização de Cache

Uma das principais inovações é a manutenção do estado da conversa diretamente nos servidores da **Google DeepMind**. Por meio do parâmetro de ID de interação anterior (`previous_interaction_id`), a aplicação cliente não precisa reenviar todo o histórico de mensagens a cada turno.

Esse mecanismo traz dois benefícios diretos:
1. **Redução de Payload**: Economia drástica de largura de banda no cliente.
2. **Eficiência de Cache de Tokens**: A preservação estrita do contexto no servidor eleva a taxa de acerto de cache de tokens de entrada (_implicit caching_), reduzindo os custos de inferência em até 90% para solicitações subsequentes.

## 2. Construção de Agentes de Codificação com Habilidades (Skills)

Durante a demonstração prática, os palestrantes demonstraram como construir um agente de codificação em Python utilizando o **Gemini 3 Flash** acoplado a habilidades declarativas (_Agent Skills_).

### 2.1 Mapeamento de Ferramentas e Esquema JSON

O agente é estruturado com ferramentas básicas de sistema de arquivos e execução de shell:
* **Ferramenta de Leitura e Escrita**: Funções que manipulam o sistema de arquivos local (`read_file` e `write_file`) mapeadas via esquemas JSON declarativos.
* **Loop Recursivo de Ação**: O cliente inspeciona o objeto de resposta da **Interactions API**. Caso o modelo retorne uma chamada de função (`requires_action`), o script local executa o código e devolve o resultado recursivamente até que o modelo decida gerar a resposta final em texto.
* **Instruções de Sistema**: A inclusão de uma instrução de sistema clara posicionando o modelo como um engenheiro de software garante o acionamento correto das ferramentas de disco.

---

## 3. Comunicação Multimodal em Tempo Real com Gemini Live API

A segunda metade do workshop detalhou a **Gemini Live API**, projetada para fluxos bidirecionais de áudio e vídeo em tempo real com baixíssima latência.

### 3.1 Arquitetura baseada em WebSockets

Diferente das requisições HTTP/REST convencionais, o **Gemini Live** estabelece uma conexão persistente via _WebSockets_.
* **Streaming Bidirecional de Áudio**: Permite enviar pacotes de áudio contínuos a partir do microfone e receber a resposta sintetizada do modelo em tempo real, suportando interrupções naturais de fala (_barge-in_).
* **Entrada de Vídeo e Câmera**: Envio de quadros de vídeo amostrados para análise contextual imediata (como a navegação em telas ou inspeção de objetos físicos através de dispositivos como óculos inteligentes ou smartphones).
* **Integração de Ferramentas ao Vivo**: O modelo mantém a capacidade de acionar chamadas de função externas (como busca na web ou APIs de geração de música via _Lyria_) sem interromper a sessão de áudio ativa.

---

## Notas Informativas

1. **Server-Sent Events (SSE)**: Padrão de comunicação web que permite ao servidor enviar atualizações assíncronas em fluxo contínuo para o cliente através de uma única conexão HTTP.
2. **Model Context Protocol (MCP)**: Especificação padronizada que possibilita a integração segura de fontes de dados e ferramentas de terceiros a modelos de linguagem.
3. **Gemini 3 Flash**: Modelo multimodal de alta velocidade da **Google DeepMind**, otimizado para inferência de baixa latência e execução eficiente de agentes autônomos.
